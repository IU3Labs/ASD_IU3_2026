# Задача 58. Заполнение матрицы змейкой — асимптотика

**Алгоритм:** для ячейки (i, j) значение вычисляется по формуле

a[i][j] = i · m + (i чётна ? j : m − 1 − j) + 1.

Направление обхода определяется чётностью строки, никаких разворотов массивов и дополнительных структур нет.

## Время

Каждая из n · m ячеек заполняется за O(1):

T(n, m) = n · m · c = **O(n · m)**

Нижняя оценка Ω(n · m) очевидна: столько чисел нужно вывести.

## Память

Результирующая матрица занимает n · m ячеек: **O(n · m)**. Это размер выхода, лучше нельзя, если матрица
должна существовать целиком. Вспомогательной памяти сверх неё нет — O(1).

## Граничный случай

n · m должно помещаться в `int` (значения идут от 1 до n · m). Проверка `Math.multiplyExact` останавливает
программу с `ArithmeticException` до выделения памяти, а не после гигантского выделения.
