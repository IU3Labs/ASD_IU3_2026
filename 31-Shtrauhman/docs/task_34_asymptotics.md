# Задача 34. Максимальная сумма подмассива — асимптотика

**Идея (алгоритм Кадане).** Для каждой позиции i храним `current` — наибольшую сумму подмассива,
который заканчивается в i. Он либо продолжает предыдущий, либо начинается заново с aᵢ:

current(i) = max(aᵢ, current(i − 1) + aᵢ)

Ответ — наибольшее `current(i)` по всем i. Наивный перебор всех подмассивов потребовал бы O(n²).

## Время

Цикл выполняется n − 1 раз, в теле — сложение и два сравнения, то есть O(1):

T(n) = c₁ · n + c₂ = **O(n)**, что совпадает с требованием задания

Нижняя оценка Ω(n) тоже верна: чтобы не пропустить лучший подмассив, нужно прочитать каждый элемент.

## Память

Хранятся две переменные (`current`, `best`) и индекс: **O(1)** дополнительной памяти.
