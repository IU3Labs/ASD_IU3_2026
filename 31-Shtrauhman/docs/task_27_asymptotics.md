# Задача 27. Сумма квадратов — асимптотика

**Алгоритм:** один проход по массиву; каждый элемент возводится в квадрат в `long`, результат прибавляется к `BigInteger`.

## Время

Цикл выполняется n раз. В теле — умножение двух `int`, приведённых к `long`, и сложение чисел ограниченной длины
(не более ~80 бит), то есть O(1):

T(n) = c · n + c′ = **O(n)**

Нижняя оценка Ω(n) тоже верна: каждый элемент нужно прочитать. Значит, алгоритм асимптотически оптимален.

## Память

Хранятся переменная `total` (`BigInteger` ограниченной длины) и индекс: **O(1)** дополнительной памяти.
