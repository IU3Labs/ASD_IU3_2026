# Задача 48. Транспонирование матрицы — асимптотика

**Алгоритм:** для всех пар (i, j) с j > i (выше главной диагонали) поменять местами `a[i][j]` и `a[j][i]`.

Если обходить всю матрицу, каждая пара поменяется дважды и вернётся на место, поэтому обход ограничен
верхним треугольником. Диагональ остаётся на месте — элемент `a[i][i]` совпадает со своим транспонированием.

## Время

Число обменов равно числу пар выше диагонали:

(n − 1) + (n − 2) + … + 1 = n(n − 1) / 2

Каждый обмен — три присваивания, то есть O(1):

T(n) = c · n(n − 1) / 2 = **O(n²)**

Это линейно по размеру входа (в матрице n² элементов), а нижняя оценка Ω(n²) очевидна: нужно затронуть почти каждый элемент.

## Память

Для обмена нужна одна временная переменная `buffer`; новая матрица не создаётся, строки остаются теми же массивами
(это проверяет тест `shouldModifyTheSameArraysWithoutAllocatingNewOnes`): **O(1)** дополнительной памяти.

## Проверка квадратности

Перед обменом метод проходит по строкам и сравнивает длину каждой с n — это O(n) времени и O(1) памяти,
на общую оценку O(n²) не влияет. Для неквадратной матрицы выбрасывается `IllegalArgumentException`,
иначе обмен вышел бы за границы строки.
