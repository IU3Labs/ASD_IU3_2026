# Задача 25. Сумма элементов — асимптотика

**Алгоритм:** один проход по массиву, накопление суммы в `long`.

## Время

Цикл выполняется ровно n раз, в теле — одно сложение и обновление индекса, то есть O(1):

T(n) = c₁ · n + c₂ = **O(n)**

Нижняя оценка Ω(n) тоже верна: чтобы получить сумму, нужно прочитать каждый элемент.
Значит, алгоритм асимптотически оптимален.

## Память

Кроме входного массива (n элементов) хранятся две переменные (`total`, индекс): **O(1)** дополнительной памяти.
Вместе с хранением входа — O(n).
