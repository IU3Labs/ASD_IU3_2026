# Задача 30. Дисперсия — асимптотика

**Формула:** D = (1/n) · Σ (aᵢ − μ)², где μ = (Σ aᵢ) / n (деление на n).

**Алгоритм:** два прохода.
1. Первый проход: сумма элементов (`long`), среднее μ.
2. Второй проход: сумма квадратов отклонений от μ (`double`).

## Время

T(n) = n (первый проход) + n (второй проход) + O(1) = 2n + c = **O(n)**

Два прохода вместо одного — константный множитель, на асимптотику он не влияет.

## Память

Переменные `sum`, `mean`, `squares`, `deviation`, индекс: **O(1)** дополнительной памяти.

## Почему не одна формула E[x²] − E[x]²

Она требует одного прохода, но при больших значениях с малым разбросом вычитает два почти равных
больших числа и теряет точность. Пример: {10⁹ − 1, 10⁹ + 1}: D = 1, а E[x²] ≈ 10¹⁸ уже
выходит за 53 бита мантиссы `double`. Двухпроходный вариант считает отклонения от среднего (малые числа)
и этой проблемы не имеет. Цена — только константный множитель 2 по времени.
