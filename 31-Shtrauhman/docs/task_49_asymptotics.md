# Задача 49. Сумма строк матрицы — асимптотика

**Алгоритм:** для каждой из n строк пройти по её m элементам и сложить их в `long`.

## Время

Вложенные циклы: внешний — n итераций, внутренний — m итераций, тело — O(1):

T(n, m) = n · m · c = **O(n · m)**

Это линейно по размеру входа (в матрице n·m элементов), нижняя оценка Ω(n·m) — каждый элемент нужно прочитать.

## Память

- Результат: массив из n сумм — **O(n)** дополнительной памяти.
- Саму матрицу (n·m чисел) программа хранит после чтения, это память под вход: O(n·m).

## Почему `long`

Строка из m значений `int` даёт сумму до m · 2³¹; уже при m = 2 это больше `Integer.MAX_VALUE`.
