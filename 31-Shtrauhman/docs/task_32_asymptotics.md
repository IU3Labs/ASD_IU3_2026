# Задача 32. Сумма произведений пар — асимптотика

**Идея O(n).** Из тождества

(Σ aᵢ)² = Σ aᵢ² + 2 · Σ_{i<j} aᵢ·aⱼ

следует

Σ_{i<j} aᵢ·aⱼ = ((Σ aᵢ)² − Σ aᵢ²) / 2.

Достаточно за один проход получить S = Σ aᵢ и Q = Σ aᵢ², дальше — арифметика над двумя числами.

## Время

- Проход по массиву: n итераций, в каждой одно сложение в `long` и одно сложение в `BigInteger`
  (числа не длиннее ~80 бит, поэтому операция выполняется за O(1)).
- После цикла: возведение S в квадрат, вычитание, деление на 2 — над числами фиксированной длины, O(1).

T(n) = c · n + c′ = **O(n)**

## Память

Хранятся `sum` (`long`), `squares` (`BigInteger`, фиксированный размер) и индекс: **O(1)** дополнительной памяти.
