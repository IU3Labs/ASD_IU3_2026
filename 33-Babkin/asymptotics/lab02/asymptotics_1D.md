# ЛР №2, задача 1D — расчёт асимптотики

**Бабкин Дмитрий Витальевич, ИУ3-33Б**

Пусть `n` — длина входного массива, одно сравнение занимает `O(1)`.

Копирование и проверка входа занимают `Θ(n)`. Просеивание узла высоты `h`
сдвигает элемент не более чем на `h` уровней. Узлов высоты хотя бы `h`
не больше `⌊n / 2^h⌋`. Если для каждого уровня сложить число узлов,
способных пройти этот уровень, получится верхняя оценка на все перемещения
`⌊n/2⌋ + ⌊n/4⌋ + ⌊n/8⌋ + … < n`.

Итого конструктор из массива работает за `Θ(n)` для `n ≥ 1`, а пустой
массив обрабатывается за `O(1)`. При последовательных вставках копирование
при росте суммарно занимает `O(n)`, а просеивания в худшем случае —
`Θ(n log n)`. Этот случай достигается, например, когда каждое следующее
значение меньше предыдущих и поднимается до корня.

Новый массив очереди занимает `Θ(n)` памяти для `n ≥ 1`. Для пустого
входа используется фиксированная начальная ёмкость. Сверх выделенного
массива конструктор и итеративное просеивание расходуют `O(1)` памяти.
