# ЛР №2, задача 3D — расчёт асимптотики

**Бабкин Дмитрий Витальевич, ИУ3-33Б**

Пусть `n` — число элементов, `k` — ширина окна. Алгоритм добавляет каждый
элемент в кучу ровно один раз и извлекает его не более одного раза. Даже
если при сдвиге окна удаляется несколько записей сразу, всего выполняется
до `n` извлечений. Куча содержит максимум `n` записей. Её операции
вставки и извлечения занимают `O(log(n + 1))` амортизированно, а чтение
вершины — `O(1)`.

Суммарное время — `O(n log n)` при `n ≥ 2`. На строго убывающем входе
каждое новое значение становится корнем и поднимается на высоту кучи,
поэтому худшая оценка достигается.

Дополнительная память для кучи — `O(n)`. На строго убывающем входе
текущий минимум всегда находится в окне, поэтому просроченные элементы
остаются внутри кучи и могут накопиться до `Θ(n)` записей.
Массив результата занимает `Θ(n - k + 1)` памяти.
