# ЛР №2, задача 1A — расчёт асимптотики

**Бабкин Дмитрий Витальевич, ИУ3-33Б**

Пусть `n` — число элементов, `C` — ёмкость массива. Считаем, что сравнение
двух элементов занимает `O(1)`. Высота непустой двоичной кучи равна
`⌊log₂ n⌋`, каждое просеивание проходит по одному пути между корнем и листом.

| Операция | Время | Обоснование |
|---|---|---|
| Пустой конструктор | `O(1)` | Выделяет массив фиксированного размера. |
| `add` | `O(log(n + 1))` амортизированно, `O(n)` при росте | Просеивание посещает не более одного узла на уровень. При росте копируется массив. |
| `poll` | `O(log(n + 1))` для непустой очереди | После замены корня выполняется одно просеивание вниз. |
| `peek`, `size`, `isEmpty` | `O(1)` | Читают корень или счётчик размера. |

До `n` вставок суммарный размер копирований при росте — геометрическая
сумма `16 + 32 + 64 + … < 2n`, если расширения происходили. Это даёт
`O(1)` амортизированного времени на рост в расчёте на вставку.

Очередь занимает `Θ(C)` памяти. Извлечения освобождают ссылки, а массив
сохраняет достигнутую ёмкость. Просеивания итеративны и требуют `O(1)`
дополнительной памяти. Во время удвоения оба массива занимают `Θ(C)` памяти.
