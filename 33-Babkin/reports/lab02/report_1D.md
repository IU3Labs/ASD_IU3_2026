# ЛР №2, задача 1D — Линейное построение кучи

**Бабкин Дмитрий Витальевич, ИУ3-33Б**

## Реализация

Конструктор `PriorityQueueCustom(T[] array)` копирует входной массив
и проверяет его элементы. Затем он вызывает `siftDown` для внутренних узлов
в порядке от `size / 2 - 1` до корня. Листья уже удовлетворяют свойству
кучи. К моменту обработки очередного родителя его дочерние поддеревья готовы,
поэтому одного просеивания вниз достаточно, чтобы построить кучу и для родителя.

## Ручная проверка

Создать очередь из `[7, 2, 5, 1]`, затем записать `-1` в последнюю
ячейку исходного массива. Четыре вызова `poll()` должны вернуть
`1, 2, 5, 7`. Порядок проверяет свойство кучи, сохранение исходной единицы
проверяет независимость копии. Конструктор из пустого массива даёт пустую
очередь, в которую можно добавлять элементы.

`PriorityQueueCustomTest` сравнивает результат построения снизу вверх
и последовательной вставки с эталонной очередью. Запуск проверок из корня
проекта — `mvn clean verify`.

На одинаковом наборе из 100 000 элементов среднее время построения снизу
вверх составило 2,569 мс, а последовательной вставки — 4,154 мс.
