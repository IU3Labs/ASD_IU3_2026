# ЛР №2, задача 3D — Скользящий минимум

**Бабкин Дмитрий Витальевич, ИУ3-33Б**

## Реализация

`SlidingMinimum.minimums(int[] arr, int k)` добавляет в собственную
очередь с приоритетом пару из значения и индекса каждого элемента. После
добавления правой границы окна алгоритм удаляет из вершины очереди записи,
чьи индексы меньше левой границы. Когда индекс вершины входит в окно,
её значение минимально среди действующих элементов: каждый из них
присутствует в куче, а вершина имеет наименьший приоритет.

Просроченные записи внутри кучи удаляются, когда поднимаются к вершине.
Индекс позволяет различить одинаковые значения. Метод возвращает один
минимум на окно слева направо и принимает размеры от 1 до длины массива.

## Ручная проверка

- Для `[2, 2, 3, 4]` и `k = 2` получается `[2, 2, 3]`. При сдвиге
  окна первая двойка выходит, вторая по-прежнему служит минимумом.
- Для `[1, 4, 2, 5]` и `k = 2` получается `[1, 2, 2]`. Единственный
  прошлый минимум удаляется после выхода из окна.

`SlidingMinimumTest` проверяет границы размера окна и сравнивает все
199 001 окно массива из 200 000 элементов при `k = 1 000` с прямым
поиском минимума в каждом окне. Запуск из корня проекта — `mvn clean verify`.
