## Обозначения и модель оценки

n — количество элементов массива.
В задачах используется ограничение 1 < n < 100000.
Элементы читаются как значения Java int.

Операции с int и long считаются операциями постоянной стоимости.
Для BigInteger размер числа учитывается отдельно.

Оценка памяти означает максимальную одновременно используемую
память алгоритма. Внутренние буферы ввода-вывода, среда Java
и память тестов в неё не включаются.

## Задача 1. Минимум и максимум

Первый элемент задаёт начальные минимум и максимум.
Остальные n − 1 элементов обрабатываются в цикле.

За одно повторение выполняются не более двух сравнений
и двух обновлений значений.

T(n) = O(1) + (n − 1) · O(1) = O(n).

Хранятся только несколько переменных.
Весь массив в памяти не сохраняется.

Время: O(n).
Дополнительная память: O(1).

## Задача 2. Индекс первого вхождения

Первый цикл читает и сохраняет n элементов.
Второй цикл ищет число и в худшем случае проверяет n элементов.

T(n) = O(n) + O(n) = O(n).

Сам поиск в лучшем случае занимает O(1), если первый элемент
совпадает с искомым. Однако вся программа и в этом случае
тратит O(n) на предварительное чтение массива.

Хранится один массив из n элементов и несколько переменных.

Время всей программы: O(n).
Память с учётом массива: O(n).
Дополнительная память самого поиска: O(1).

## Задача 25. Сумма элементов

Цикл выполняется n раз.
В каждом повторении читается число и выполняется одно сложение.

T(n) = n · O(1) = O(n).

Массив не сохраняется. Сумма хранится в long.
При заданных ограничениях её модуль не превышает
n · 2^31 < 2^48, что помещается в long.

Время: O(n).
Дополнительная память: O(1).

## Задача 27. Сумма квадратов

Цикл выполняется n раз.
Для каждого числа вычисляется квадрат и обновляется сумма.

Квадрат любого значения int не превышает 2^62,
поэтому умножение выполняется в long без переполнения.
Сумма хранится в BigInteger.

Сумма не превышает n · 2^62.
При n < 100000 она меньше 2^79.
Следовательно, для допустимых входных данных операции
над суммой работают с ограниченным количеством разрядов.

В принятой модели для заданных ограничений:
время — O(n), дополнительная память — O(1).

Уточнение для неограниченного роста n:
длина суммы составляет O(log n) бит.
Сложение и создание нового BigInteger требуют
O(log n) времени в худшем случае.

Тогда время накопления суммы — O(n log n),
максимальная дополнительная память — O(log n) бит.
Это пиковая память, а не суммарный объём всех временных
объектов, созданных за выполнение программы.

## Задача 31. Скалярное произведение

Первый цикл сохраняет n элементов первого массива.
Второй цикл читает n элементов второго массива
и прибавляет соответствующие произведения к сумме.

Оба цикла последовательные, а не вложенные.

Произведение двух значений int помещается в long:
его модуль не превышает 2^62.
Модуль любой промежуточной суммы не превышает n · 2^62.
Сумма хранится в BigInteger.

При n < 100000 её модуль меньше 2^79,
поэтому стоимость операций над суммой ограничена.

В принятой модели для заданных ограничений:
T(n) = O(n) + O(n) = O(n).

Первый массив хранится в памяти, второй обрабатывается
последовательно и не сохраняется.

Время: O(n).
Память с учётом первого массива: O(n).
Дополнительная память сверх первого массива: O(1)
при заданных ограничениях.

При неограниченном росте n операции с BigInteger дают
O(n log n) времени и O(log n) бит памяти для суммы.
Общая память с учётом массива остаётся O(n).

## Задача 36. Бегущая сумма

Цикл выполняется n раз.
Каждое повторение читает число, обновляет сумму
и выводит один результат.

При заданных ограничениях все промежуточные суммы
помещаются в long. Длина выводимого числа ограничена.

T(n) = n · O(1) = O(n).

Исходный массив и массив результата не сохраняются.
Результаты последовательно выводятся в стандартный поток.

Время: O(n).
Дополнительная память: O(1).

## Задача 37. Разворот массива на месте

Чтение массива выполняется за n повторений.
Разворот выполняет floor(n / 2) обменов.
Вывод выполняется за n повторений.

Каждый обмен состоит из постоянного количества операций.

T(n) = O(n) + O(floor(n / 2)) + O(n) = O(n).

Разворот использует только индексы и временную переменную.
Второй массив не создаётся.

Время самого разворота: O(n).
Дополнительная память разворота: O(1).

Время всей программы: O(n).
Память всей программы с исходным массивом: O(n).
