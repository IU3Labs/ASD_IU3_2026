# Расчёт асимптотики. Лабораторная работа №2

## Задача 1A. Очередь с приоритетом

n — текущее количество элементов. Высота двоичной кучи — O(log n).

| Операция | Время | Обоснование |
|---|---|---|
| `add` | O(log n) амортизированно | Просеивание вверх проходит не больше высоты кучи. Вставка с расширением занимает O(n) из-за копирования массива. |
| `poll` | O(log n) | Последний элемент переносится в корень и просеивается вниз. |
| `peek`, `size`, `isEmpty` | O(1) | Читаем корень массива или счётчик элементов. |

Массив занимает O(C) памяти, где C — его ёмкость. После извлечений
ёмкость не уменьшается. Просеивание использует O(1) дополнительной
памяти; при расширении временно создаётся новый массив размером O(n).

## Задача 1C. Удаление элемента по значению

Поиск занимает O(n) в худшем случае, где n — число элементов очереди.
После замены найденного элемента последним просеивание занимает
не более O(log n). Итого `remove` работает за O(n) в худшем случае
и использует O(1) дополнительной памяти.
