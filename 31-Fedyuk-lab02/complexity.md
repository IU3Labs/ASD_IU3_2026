# Расчёт времени и памяти

n — число элементов, C — ёмкость хеш-таблицы. Сравнение элементов, hashCode и equals
считаются O(1); если они сами обрабатывают длинные строки или сложные объекты,
их стоимость нужно дополнительно учитывать. Память результата включена в оценки.

## Очередь с приоритетом: 1A–1D

| Операция | Время | Дополнительная память операции |
|---|---|---|
| add без расширения | O(log n) | O(1) |
| add с расширением | O(n) | O(n) на новый массив |
| add амортизированно | O(log n) | очередь хранит O(n) ссылок |
| peek, size, isEmpty | O(1) | O(1) |
| poll | O(log n) | O(1) |
| remove(item) | O(n) + O(log n) = O(n) | O(1) |
| Конструктор из массива | O(n) | O(n) на копию |
| Последовательные n добавлений | O(n log n) в худшем случае | O(n) |

Высота двоичной кучи равна floor(log₂ n). Каждый шаг siftUp или siftDown проходит
один уровень и делает константное число сравнений. Минимальный элемент хранится
в корне; извлечение переносит последний элемент в корень и просеивает его вниз.
При удалении из середины замещающий элемент может потребовать движения вверх или вниз.

Массив удваивается при заполнении. За m добавлений суммарно копируется
16 + 32 + 64 + … < 2m элементов, поэтому копирование стоит O(1) амортизированно.
Вместе с просеиванием получаем O(log n) амортизированно для add. Строгое худшее
время отдельного add при обычном расширяемом массиве — O(n), что важно отличать
от указанной в условии логарифмической стоимости работы с кучей.

В heapify просеивание запускается от последнего внутреннего узла к корню.
Узлов с высотой h не более n/2^(h+1), поэтому суммарная работа ограничена
n × Σ(h / 2^(h+1)) = O(n). Копирование входного массива также занимает O(n).
Тест дополнительно проверяет, что на 100 000 значений построение делает меньше 2n сравнений.

Очередь не сжимает массив после удаления: фактически занимает O(Nmax), где Nmax —
максимальное количество одновременно хранившихся элементов. Удалённые ссылки очищаются.

## Хеш-таблица: 2A и 2C

| Операция | Ожидаемое время при хорошем распределении | Худшее время |
|---|---|---|
| get, containsKey, remove | O(1) | O(C) |
| put без перехеширования | O(1) | O(C) |
| put с учётом расширений и очисток | O(1) амортизированно | O(C²) при тяжёлых коллизиях и перехешировании |
| size, capacity | O(1) | O(1) |

Линейное пробирование проверяет последовательные ячейки по кругу. Поиск заканчивается
на пустой ячейке; DELETED не прерывает поиск. Цикл поиска явно ограничен ёмкостью.
При вставке сначала ищется существующий ключ, поэтому удалённая ячейка перед ним
не создаёт дубликат. Для нового ключа выбирается первая пустая или удалённая ячейка.

Загрузка живыми записями ограничена 3/4. При превышении ёмкость удваивается.
Число занятых ячеек вместе с DELETED ограничивается 7/8: при превышении выполняется
очистка перехешированием в ту же ёмкость. Между очистками требуется накопить
порядка C удалённых ячеек; это не запускает полную очистку после каждой пары
«удаление + вставка» около порога 0.75.

При хорошем распределении перехеширование занимает O(C), а удвоение даёт O(1)
амортизированных затрат на вставку. При постоянном хеше повторная вставка всех
записей может сама требовать 1 + 2 + … + n проверок, то есть O(n²); поэтому нельзя
обещать линейное перехеширование в худшем случае для открытой адресации.

Таблица занимает O(C) памяти: два массива ссылок. Перехеширование временно сохраняет
старые массивы, но порядок памяти остаётся O(C). Автоматического сжатия нет, поэтому
после массовых удалений память зависит от сохранённой ёмкости, а не только от текущего n.

## Скользящий минимум: 3D

В кучу добавляется n записей (значение, исходный индекс). Устаревшие записи удаляются
только когда оказываются в корне. Каждая запись добавляется один раз и извлекается
не более одного раза, поэтому суммарное время — O(n log n), даже при цикле while
внутри прохода по массиву.

Куча может хранить O(n) записей, а не только O(k): например, в убывающем массиве
старые большие значения остаются под новыми минимумами. Результат занимает
O(n − k + 1); общая дополнительная память — O(n). Входной массив не изменяется.
