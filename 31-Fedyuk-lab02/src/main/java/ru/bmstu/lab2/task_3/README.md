# Задача 3D. Скользящий минимум

Идея: добавлять в собственную очередь пары (значение, индекс), затем удалять
устаревшие элементы из корня. Для полного окна значение корня записывается в ответ.

Время: O(n log n). Каждая запись добавляется и удаляется не более одного раза.

Дополнительная память: O(n), включая кучу и результат. Ленивое удаление не гарантирует
кучу размера O(k): устаревшие записи могут оставаться внутри неё.

Пример: [4, 2, 5, 1], k = 2 → [2, 2, 1]. Исходный массив сохраняется.
Окно должно удовлетворять 1 ≤ k ≤ n; иначе выбрасывается IllegalArgumentException.
Для null-массива выбрасывается NullPointerException.
