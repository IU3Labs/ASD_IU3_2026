# Задачи 1A–1D. Очередь с приоритетом

Идея: хранить двоичную кучу в расширяемом массиве. siftUp восстанавливает порядок
после добавления, siftDown — после замены корня. Компаратор выбирает min- или max-heap.
Удаление по значению сначала ищет совпадение; после замены последним элементом
выбирается подходящее направление просеивания. Конструктор из массива строит кучу снизу вверх.

Время: peek/size/isEmpty — O(1), poll — O(log n), remove — O(n), heapify — O(n).
Добавление — O(log n) амортизированно; при расширении один вызов может занимать O(n).

Память: O(Nmax), где Nmax — максимальный достигнутый размер очереди, так как сжатия нет.

Пример: добавить 4, 1, 3. Min-heap извлекает 1, 3, 4; обратный компаратор — 4, 3, 1.
Null-элементы запрещены; peek и poll пустой очереди бросают NoSuchElementException.
Без компаратора требуется естественный порядок Comparable.
