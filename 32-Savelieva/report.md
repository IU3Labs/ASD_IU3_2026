# Лабораторная работа № 2. Структуры данных

Реализованы (по одному заданию из каждой группы):

## Задача 1A — PriorityQueueCustom<T>
Бинарная min-куча на динамическом массиве.

| Метод      | Асимптотика       |
|------------|-------------------|
| `add(T)`   | O(log n)          |
| `poll()`   | O(log n)          |
| `peek()`   | O(1)              |
| `size()`   | O(1)              |
| `isEmpty()`| O(1)              |

Ключевые решения:
- индексация детей `2i+1`, `2i+2`, родителя `(i-1)/2`;
- отдельные `siftUp`/`siftDown`;
- автоматическое удвоение массива (`Arrays.copyOf`);
- `poll`/`peek` на пустой очереди бросают `NoSuchElementException`;
- `null` запрещён (`NullPointerException`).

## Задача 2A — HashMapCustom<K, V> (линейное пробирование)
Открытая адресация с линейным пробированием.

| Метод             | Асимптотика (амортиз.) |
|-------------------|------------------------|
| `put(K, V)`       | O(1)                   |
| `get(K)`          | O(1)                   |
| `containsKey(K)`  | O(1)                   |
| `remove(K)`       | O(1)                   |
| `size()`          | O(1)                   |
| `capacity()`      | O(1)                   |

Ключевые решения:
- хеш: `Math.abs(key.hashCode()) % capacity`;
- load factor ≤ 0.75, при превышении — удвоение ёмкости с перехешированием;
- удалённые ячейки помечаются маркером `DELETED`, чтобы не разрывать цепочки пробирования;
- `DELETED`-слоты переиспользуются при вставке (см. `findSlot`).

## Задача 3A — TopK.topK
Возвращает k наибольших элементов за O(n log k) с помощью собственной min-кучи размера k.
Сравнение с полной сортировкой — в `benchmarks.md`.

## Тесты
JUnit 5. По каждой структуре — ≥ 10 тестов, включая граничные случаи:
пустая структура, один элемент, дубликаты, авто-расширение, удаление середины кластера,
переиспользование `DELETED`-слотов, стресс-тест против эталонной `java.util`-реализации.

Запуск: `mvn test`.
