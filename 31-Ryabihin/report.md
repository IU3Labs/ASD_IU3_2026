# Лабораторная работа № 2. Структуры данных

Рябихин Виталий, группа ИУ3-31Б.

| Задача | Решение | Баллы по условию |
|---|---|---:|
| 2A | `HashMapCustom` на массиве с линейным пробированием, маркером `DELETED` и ростом при пороге 0.75 | 3 |
| 2B | Квадратичное пробирование со смещением `i + 2i²` и сравнением числа проб на 50 000 поисках | 3 |
| 2C | Вставка, поиск и удаление в наборе из 10 000 ключей с одинаковым хешем | 3 |
| 2D | Порог загрузки в конструкторе и сравнение порогов 0.50, 0.75 и 0.90 | 3 |
| **Итого** | | **12** |

Открытая адресация позволяет хранить записи в одном массиве. При коллизии пробирование выбирает следующую ячейку, а маркер удаления сохраняет путь до записей за ней. Для квадратичного варианта ёмкость остаётся степенью двойки, а формула смещения позволяет обойти весь массив.

Таблица операций с асимптотикой и доказательство обхода приведены в [complexity.md](complexity.md). Сравнение с `java.util.HashMap` и условия запуска замеров приведены в [benchmarks.md](benchmarks.md).

## Ручные проверки

| Действия с новой таблицей | Ожидаемый результат | Что проверяется |
|---|---|---|
| `put(0, "A")`, `put(16, "B")`, `remove(0)`, `get(16)` | `"B"` | Удаление в начале цепочки из двух ключей с общей стартовой ячейкой |
| `put("a", null)`, `containsKey("a")`, `get("a")` | `true`, `null` | Наличие ключа со значением `null` |
| Вставка ключей от 0 до 12 с порогом 0.75 | `size() == 13`, `capacity() == 32`, все значения доступны | Перехеширование при превышении порога |
