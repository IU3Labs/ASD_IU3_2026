# ЛР2. Хеш-таблица

`HashMapCustom<K, V>` из пакета `ru.bmstu.lab2.task_2` хранит пары в массиве с открытой адресацией. Конструктор без параметров задаёт линейное пробирование и порог 0.75. Ключ должен быть ненулевым, значение может быть `null`.

Оценки операций приведены в [complexity.md](complexity.md), результаты замеров — в [benchmarks.md](benchmarks.md).
