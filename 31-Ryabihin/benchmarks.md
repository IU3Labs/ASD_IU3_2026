# Бенчмарки хеш-таблиц

Замеры выполнены на Intel Core i5-12600K под Windows 11 с Eclipse Temurin 25.0.4.1. Для каждого случая было три прогревочных запуска и пять измерительных. Таблицы показывают среднее время на всю указанную серию операций. Данные и запросы созданы заранее с фиксированным зерном генератора. Время вставки включает выделение записей и рост таблицы.

Запуск из корня репозитория в PowerShell

```powershell
mvn -f 31-Ryabihin/pom.xml test-compile
$classes = '31-Ryabihin/target/test-classes;31-Ryabihin/target/classes'
java -Xms256m -Xmx512m -cp $classes ru.bmstu.lab2.task_2.HashMapBenchmark
```
