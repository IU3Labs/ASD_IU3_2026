# Отчёт по Заданию №25: Сумма элементов

**Студент:** Хусаинов Тимур, группа ИУ3-32

---

Дан массив целых чисел `a` длины `n` (по условию `2 < n < 100 000`).
Требуется вычислить сумму всех элементов массива.


### Идея решения
Алгоритм использует **один линейный проход** по массиву:

1. Инициализируем переменную `sum` типа `long` нулём.
2. Проходим по всем элементам массива от индекса `0` до `n - 1`.
3. На каждом шаге прибавляем текущий элемент `array[i]` к общей сумме.
4. Возвращаем итоговое значение `sum`.

**Важное замечание по типам данных:** тип возвращаемого значения и аккумулятора выбран `long`, а не `int`. Так как массив может содержать значения, близкие к `Integer.MAX_VALUE`, их сумма легко превысит максимально возможное значение `int`. Использование `long` гарантирует отсутствие переполнения на всём допустимом диапазоне входных данных.


### Анализ асимптотики

1. **Время**

- **`O(n)`**, где `n` — длина массива.
- Обоснование: цикл `for` выполняется ровно `n` раз, каждое сложение — `O(1)`. 
- Инициализация суммы — `O(1)`.
- Итог: суммарно `O(n)`.

2. **Память**

- **`O(1)`** дополнительной памяти.
- Обоснование: используется только одна переменная-аккумулятор `sum` и счетчик цикла. Дополнительные массивы или структуры данных не создаются.
- Итог: `O(1)` (не считая входного массива).
