# Отчёт по Заданию №5: Сумма элементов на чётных позициях

**Студент:** Хусаинов Тимур, группа ИУ3-32

---

Дан массив целых чисел `a` длины `n` (по условию `2 < n < 100 000`).
Требуется вычислить сумму элементов, стоящих на чётных индексах (0, 2, 4, ...).


### Идея решения
Алгоритм использует **линейный проход с шагом 2**:

1. Инициализируем переменную `sum` типа `long` для накопления суммы нулём.
2. Запускаем цикл `for` от индекса `0` до конца массива с шагом `i += 2`.
3. На каждом шаге к текущей сумме прибавляем элемент `array[i]`.
4. Возвращаем итоговое значение `sum`.

**Важное замечание по типам данных:** тип возвращаемого значения и аккумулятора выбран `long`, а не `int`. Если массив заполнен значениями `Integer.MAX_VALUE`, их сумма превысит максимально возможное значение `int`, что приведет к переполнению. Использование `long` гарантирует корректность вычислений на всём допустимом диапазоне входных данных.


### Анализ асимптотики

1. **Время**

- **`O(n)`**, где `n` — длина массива.
- Обоснование: алгоритм совершает ровно `n / 2` итераций. В асимптотической нотации константа `1/2` отбрасывается, оставляя сложность `O(n)`.
- Итог: суммарно `O(n)`.

2. **Память**

- **`O(1)`** дополнительной памяти.
- Обоснование: используется только одна переменная-аккумулятор `sum` и счетчик цикла. Дополнительные массивы или структуры данных не создаются.
- Итог: `O(1)` (не считая входного массива).
