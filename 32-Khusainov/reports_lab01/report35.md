# Отчёт по Заданию №35: Префиксные суммы

Дан массив целых чисел `a` длины `n` (по условию `2 < n < 100 000`) и `q` запросов вида `[l, r]`.
Для каждого запроса требуется найти сумму элементов с `l` по `r` включительно.
Требование: предпосчёт, затем `O(1)` на каждый запрос.


### Идея решения
Вместо того чтобы каждый раз суммировать элементы в цикле (что дало бы `O(n)` на запрос), мы используем **метод префиксных сумм**:

1. Создаём вспомогательный массив `prefix` длины `n + 1` (тип `long` для защиты от переполнения).
2. Заполняем его: `prefix[0] = 0`, `prefix[i + 1] = prefix[i] + array[i]`. 
   Теперь `prefix[k]` хранит сумму элементов от `0` до `k - 1`.
3. Чтобы найти сумму элементов от `l` до `r` включительно, достаточно вычислить `prefix[r + 1] - prefix[l]`.

Таким образом, предпосчёт занимает один проход, а каждый последующий запрос выполняется за строго `O(1)`.


### Анализ асимптотики

1. **Время**

- **Предпосчёт:** `O(n)` — один проход по массиву.
- **Запрос:** `O(1)` на каждый из `q` запросов.
- **Итог:** суммарно `O(n + q)`.

2. **Память**

- **`O(n)`** дополнительной памяти.
- Обоснование: создаётся массив префиксных сумм `prefix` длиной `n + 1`. Массив результатов имеет размер `q`, но он является возвращаемым значением. Тип `long` гарантирует, что сумма не переполнится.
- Итог: `O(n)`.
