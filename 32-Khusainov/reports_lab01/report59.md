# Отчёт по Заданию №59: Определитель матрицы 3×3

**Студент:** Хусаинов Тимур, группа ИУ3-32

---

Вход: матрица `3 x 3` из целых чисел.
Выход: определитель матрицы.


### Идея решения
Алгоритм реализует прямое вычисление определителя по формуле разложения по первой строке (правило Саррюса):

`det = a*(ei - fh) - b*(di - fg) + c*(dh - eg)`

1. Считываем элементы матрицы в 9 переменных (`a, b, c, d, e, f, g, h, i`).
2. Сразу приводим их к типу `long` при сохранении, чтобы избежать переполнения при последующих умножениях.
3. Вычисляем результат по формуле за константное время.

**Важное замечание по типам данных:** результат вычисляется в `long`. При умножении трёх чисел типа `int` (например, `Integer.MAX_VALUE` в кубе) результат гарантированно выйдет за пределы `int`. Использование `long` предотвращает появление неверных (отрицательных) значений.


### Анализ асимптотики

1. **Время**

- **`O(1)`**.
- Обоснование: размер матрицы строго фиксирован (3×3). Выполняется фиксированное количество операций умножения и сложения (9 чтений, 12 умножений, 5 сложений/вычитаний), не зависящее от входных данных.

2. **Память**

- **`O(1)`** дополнительной памяти.
- Обоснование: используются только 9 переменных типа `long` для хранения элементов матрицы. Дополнительные структуры данных не создаются.
- Итог: `O(1)`.
