# Отчёт по Заданию №3: Подсчёт вхождений

**Студент:** Хусаинов Тимур, группа ИУ3-32

Дан массив целых чисел `a` длины `n` (по условию `2 < n < 100 000`) и число `x`.
Требуется подсчитать количество элементов массива, равных `x`.


### Идея решения
Алгоритм основан на **полном линейном проходе** по массиву со счётчиком:

1. Инициализируем переменную-счётчик `count` нулём.
2. Проходим по всем элементам массива от индекса `0` до `n - 1`.
3. Для каждого элемента проверяем условие `array[i] == x`.
4. Если условие истинно — увеличиваем `count` на единицу.
5. После завершения цикла возвращаем итоговое значение `count`.


### Анализ асимптотики

1. **Время**

- **`O(n)`**, где `n` — длина массива.
- Обоснование: цикл `for` выполняется ровно `n` раз (от `0` до `n - 1`), каждое сравнение и инкремент — `O(1)`. Досрочный выход невозможен, так как нужно просмотреть весь массив.
- Инициализация счётчика — `O(1)`.
- Итог: суммарно `O(n)` в любом случае (и в лучшем, и в худшем).

2. **Память**

- **`O(1)`** дополнительной памяти.
- Обоснование: для работы алгоритма используется только одна переменная `count` для хранения количества совпадений, независимо от размера входного массива.
- Итог: `O(1)` (не считая входного массива).
