# Отчёт по Заданию №9: Проверка отсортированности

**Студент:** Хусаинов Тимур, группа ИУ3-32

---

Дан массив целых чисел `a` длины `n` (по условию `2 < n < 100 000`).
Требуется проверить, является ли массив неубывающим.
Выход: строка "YES", если массив неубывающий; строка "NO" иначе.


### Идея решения
Алгоритм использует **линейный проход** с попарным сравнением:

1. Запускаем цикл `for` с индекса `1` (второй элемент) до конца массива.
2. На каждом шаге сравниваем текущий элемент `array[i]` с предыдущим `array[i - 1]`.
3. Если `array[i] < array[i - 1]` — порядок нарушен, массив не является неубывающим. Сразу возвращаем строку `"NO"` (досрочный выход).
4. Если цикл завершился и ни одного нарушения не найдено, возвращаем строку `"YES"`.


### Анализ асимптотики

1. **Время**

- **`O(n)`** в худшем случае, где `n` — длина массива.
- Обоснование: если массив отсортирован, цикл выполнится ровно `n - 1` раз, каждое сравнение — `O(1)`. В худшем случае сложность линейна.
- **`O(1)`** в лучшем случае (если нарушение порядка стоит на первом же шаге цикла).
- Итог: асимптотическая сложность — `O(n)`.

2. **Память**

- **`O(1)`** дополнительной памяти.
- Обоснование: используется только счетчик цикла `i`. Строки "YES" и "NO" являются константными литералами в пуле строк, дополнительная динамическая память под них не выделяется.
- Итог: `O(1)` (не считая входного массива).


### Список тестов
