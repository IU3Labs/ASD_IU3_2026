# Отчет по Лабораторной работе №1 — Задача 1: Максимум и минимум

## 1. Идея решения
Для поиска минимального и максимального элементов инициализируем переменные `min` и `max` первым элементом массива. Затем в цикле проходим по всем остальным элементам массива ровно один раз, сравнивая текущий элемент с текущими значениями `min` и `max`. При обнаружении меньшего или большего значения обновляем соответствующие переменные.

## 2. Анализ асимптотической сложности
- **Время (Time Complexity):** O(n), где n — количество элементов в массиве. Мы совершаем один проход по массиву из n элементов.
- **Память (Space Complexity):** O(1). Дополнительная память расходуется только на несколько переменных (`min`, `max`, индекс цикла), независимо от размера входного массива.

## 3. Примеры тестов
- Стандартный массив с разбросанными числами.
- Массив из одного элемента (проверка граничного условия).
- Пустой массив (проверка выброса исключения).
