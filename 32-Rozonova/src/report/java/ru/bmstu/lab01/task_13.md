# Отчет по Лабораторной работе №1 — Задача 13: Сортировка выбором

## 1. Идея решения
Алгоритм сортировки выбором делит массив на две части: отсортированную (в начале) и неотсортированную (в оставшейся части). На каждом шаге алгоритм ищет минимальный элемент в неотсортированной части массива и меняет его местами с первым элементом неотсортированной части, после чего граница отсортированной части сдвигается на один элемент вправо.

## 2. Анализ асимптотической сложности
- **Время (Time Complexity):** O(n^2) в худшем, среднем и лучшем случаях. На первой итерации делается n-1 сравнений, на второй n-2 и т.д. Общее количество сравнений составляет сумму арифметической прогрессии: (n-1) + (n-2) + ... + 1 = n * (n - 1) / 2, что дает квадратичную сложность O(n^2).
- **Память (Space Complexity):** O(1). Сортировка происходит на месте (in-place), дополнительная память расходуется только на несколько вспомогательных переменных (`minIndex`, `temp`, итераторы циклов).

## 3. Примеры тестов
- Стандартный несортированный массив с разбросанными числами.
- Массив, который уже отсортирован (проверка стабильности работы алгоритма).
- Массив, отсортированный в обратном порядке.
- Массив с повторяющимися элементами.
- Граничный случай: массив из одного элемента.
