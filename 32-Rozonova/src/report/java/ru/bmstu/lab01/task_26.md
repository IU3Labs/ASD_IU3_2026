# Отчет по Лабораторной работе №1 — Задача 26: Произведение элементов

## 1. Идея решения
Для нахождения произведения всех элементов массива по модулю $10^9 + 7$ используется последовательный проход по массиву. На каждой итерации текущий элемент умножается на текущее накопленное произведение, после чего результат берется по модулю $10^9 + 7$. Для предотвращения переполнения типа данных промежуточные вычисления ведутся в типе `long`. Также предусмотрена корректная обработка отрицательных чисел при взятии остатка.

## 2. Анализ асимптотической сложности
- **Время (Time Complexity):** $O(n)$, где $n$ — количество элементов в массиве. Алгоритм выполняет один проход по всем элементам.
- **Память (Space Complexity):** $O(1)$. Дополнительная память расходуется только на переменные под произведение и итератор цикла.

## 3. Примеры тестов
- Стандартный массив с положительными числами.
- Массив, содержащий нуль (проверка обнуления произведения).
- Массив с отрицательными числами (проверка корректности знаков).
- Массив с большими числами (проверка взятия остатка по модулю $10^9 + 7$).
- Граничный случай: пустой массив (возвращает нейтральный элемент умножения — 1).
