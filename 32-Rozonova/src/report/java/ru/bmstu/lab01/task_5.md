# Отчет по Лабораторной работе №1 — Задача 5: Сумма элементов на чётных позициях

## 1. Идея решения
Для нахождения суммы элементов на чётных позициях (индексы 0, 2, 4 и т. д.) используется проход по массиву с шагом 2. Цикл начинается с индекса `0` и на каждой итерации увеличивается на `2` (`i += 2`). Это позволяет суммировать только нужные элементы напрямую, избегая проверки условий чётности через оператор взятия остатка.

## 2. Анализ асимптотической сложности
- **Время (Time Complexity):** O(n), где n — количество элементов в массиве. Мы просматриваем примерно половину элементов массива, что асимптотически эквивалентно O(n).
- **Память (Space Complexity):** O(1). Дополнительная память расходуется только на переменную под сумму (`sum`) и счётчик цикла (`i`).

## 3. Примеры тестов
- Стандартный массив нечётной длины (проверка корректности выборки элементов по чётным индексам).
- Массив чётной длины.
- Массив из одного элемента.
- Пустой массив (проверка граничного условия).
