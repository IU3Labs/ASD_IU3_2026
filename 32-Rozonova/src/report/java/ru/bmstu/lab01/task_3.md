# Отчет по Лабораторной работе №1 — Задача 3: Подсчёт вхождений

## 1. Идея решения
Для подсчёта количества вхождений заданного числа x в массив используется линейный проход по всем элементам массива. Мы заводим счётчик `count`, инициализированный нулём, и проходим по каждому элементу массива с помощью цикла. Если текущий элемент равен искомому значению, увеличиваем счётчик на единицу. По окончании прохода возвращаем итоговое значение счётчика.

## 2. Анализ асимптотической сложности
- **Время (Time Complexity):** O(n), где n — количество элементов в массиве. Мы обязаны проверить каждый элемент массива ровно один раз, чтобы узнать, равен ли он искомому значению.
- **Память (Space Complexity):** O(1). Дополнительная память расходуется только на переменную счётчика `count` и итератор цикла, независимо от размера входного массива.

## 3. Примеры тестов
- Массив, в котором искомый элемент встречается несколько раз (проверка корректности подсчёта).
- Массив, в котором искомый элемент полностью отсутствует (проверка возврата нуля).
- Граничный случай: пустой массив (проверка безопасности выполнения).
- Граничный случай: массив, состоящий только из искомых элементов (проверка совпадения длины массива и результата).
