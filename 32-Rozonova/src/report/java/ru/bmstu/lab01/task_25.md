# Отчет по Лабораторной работе №1 — Задача 25: Сумма элементов

## 1. Идея решения
Для нахождения суммы всех элементов массива используется линейный проход по каждому элементу. Заводится переменная `sum` типа `long` (для предотвращения возможного переполнения при больших значениях элементов или длинных массивах), в которую последовательно добавляется значение каждого элемента массива.

## 2. Анализ асимптотической сложности
- **Время (Time Complexity):** O(n), где n — количество элементов в массиве. Мы совершаем ровно один проход по всем элементам массива.
- **Память (Space Complexity):** O(1). Дополнительная память расходуется только на переменную для хранения накопительной суммы и итератор цикла.

## 3. Примеры тестов
- Стандартный массив с положительными числами.
- Массив, содержащий как положительные, так и отрицательные числа.
- Массив из одного элемента.
- Пустой массив (граничный случай, возвращающий 0).
