# Отчет по Лабораторной работе №1 — Задача 27: Сумма квадратов

## 1. Идея решения
Для нахождения суммы квадратов всех элементов массива используется линейный проход по элементам. На каждой итерации текущее значение элемента возводится в квадрат. Во избежание переполнения типа `int` при умножении и суммировании, промежуточные вычисления и накопительная сумма хранятся в переменной типа `long`.

## 2. Анализ асимптотической сложности
- **Время (Time Complexity):** $O(n)$, где $n$ — количество элементов в массиве. Алгоритм совершает ровно один проход по всем элементам массива.
- **Память (Space Complexity):** $O(1)$. Дополнительная память расходуется только на переменную для хранения суммы и итератор цикла.

## 3. Примеры тестов
- Стандартный массив с положительными числами.
- Массив с отрицательными числами (проверка корректности возведения в квадрат).
- Массив из одного элемента.
- Пустой массив (граничный случай, возвращающий 0).
