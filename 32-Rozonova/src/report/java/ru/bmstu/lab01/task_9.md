# Отчет по Лабораторной работе №1 — Задача 9: Проверка отсортированности

## 1. Идея решения
Для проверки того, является ли массив неубывающим, используется последовательный проход по элементам от первого до предпоследнего. На каждой итерации текущий элемент `array[i]` сравнивается со следующим `array[i + 1]`. Если обнаруживается нарушение порядка (`array[i] > array[i + 1]`), массив не отсортирован, возвращается `false`. Если цикл завершился без нарушений, массив считается отсортированным, возвращается `true`.

## 2. Анализ асимптотической сложности
- **Время (Time Complexity):** O(n), где n — количество элементов в массиве. В худшем случае мы проверяем элементы за один проход. При первом же нарушении алгоритм завершается досрочно (лучший случай O(1)).
- **Память (Space Complexity):** O(1). Дополнительная память не выделяется, используется только итератор цикла.

## 3. Примеры тестов
- Неубывающий массив с повторяющимися элементами (проверка нестрогого порядка).
- Неотсортированный массив (проверка возврата `NO`/`false`).
- Массив из одного элемента и пустой массив (граничные случаи).
