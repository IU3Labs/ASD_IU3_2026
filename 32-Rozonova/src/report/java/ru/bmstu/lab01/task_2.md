# Отчет по Лабораторной работе №1 — Задача 2: Индекс первого вхождения

## 1. Идея решения
Для поиска индекса первого вхождения искомого элемента $x$ используется алгоритм линейного поиска. Проходим по массиву слева направо (начиная с индекса `0`). Как только встречаем элемент, равный $x$, сразу же возвращаем текущий индекс $i$. Если до конца массива элемент не найден, возвращаем `-1`.

## 2. Анализ асимптотической сложности
- **Время (Time Complexity):** $O(n)$ в худшем случае (когда элемент находится в самом конце массива или отсутствует). В лучшем случае — $O(1)$ (если элемент стоит на первой позиции).
- **Память (Space Complexity):** $O(1)$. Дополнительная память расходуется только на переменную-счётчик цикла `i`.

## 3. Примеры тестов
- Поиск элемента, присутствующего в массиве несколько раз (проверка возврата именно первого индекса).
- Поиск отсутствующего элемента (проверка возврата `-1`).
- Граничный случай: элемент находится на нулевой позиции.
- Граничный случай: пустой массив.
