# Отчет по Лабораторной работе №2 — Задача 1C: 

## 1. Архитектура и алгоритм удаления
В стандартной бинарной куче поиск элемента по значению требует линейного обхода массива, так как куча не упорядочена горизонтально. 
- **Поиск индекса:** Выполняется линейным сканированием за $O(n)$.
- **Замена и восстановление:** Найденный элемент заменяется последним элементом кучи, после чего размер уменьшается. Для восстановления инварианта кучи вызывается либо `siftUp`, либо `siftDown` (в зависимости от сравнения с родителем) за $O(\log n)$.

## 2. Анализ асимптотической сложности
- **`remove(T item)`**: $O(n)$ в худшем случае (поиск занимает $O(n)$, а просеивание — $O(\log n)$).
- Остальные методы сохраняют стандартную асимптотику бинарной кучи.

## 3. Тестирование
Реализован набор модульных тестов (JUnit 5), покрывающих удаление корня, удаление узла из середины структуры с проверкой восстановления свойств кучи, удаление отсутствующего элемента и безопасную обработку пустой очереди.
