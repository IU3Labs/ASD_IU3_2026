# Отчет по Лабораторной работе №2 — Задача 2A

## 1. Архитектура и особенности реализации
Класс `HashMapCustom<K, V>` реализует хеш-таблицу методом открытой адресации с линейным пробированием:
- **Хеш-функция:** `(key.hashCode() & 0x7fffffff) % capacity` для безопасного исключения отрицательных значений при вычислении остатка.
- **Маркер удалений (`DELETED`):** Удаление элемента не зануляет ячейку физически, а устанавливает специальный маркер-заглушку. Это предотвращает обрыв цепочек линейного пробирования при последующем поиске.
- **Динамическое расширение:** При достижении коэффициента загрузки $\ge 0.75$ (учитываются как активные элементы, так и маркеры `DELETED`) происходит увеличение емкости массива в 2 раза с полным рехешированием.

## 2. Анализ асимптотической сложности
- **`put` / `get` / `remove`**: $O(1)$ в среднем случае (при малом количестве коллизий) и $O(n)$ в худшем случае при сильной кластеризации.
- **Память (Space Complexity)**: $O(n)$ для хранения элементов в массиве таблиц.

## 3. Тестирование
Реализован исчерпывающий набор модульных тестов (JUnit 5), проверяющих вставку, обновление, поиск, удаление, коллизии при линейном пробировании, корректность работы со спецмаркером `DELETED` и автоматический `resize` при превышении `loadFactor`.
