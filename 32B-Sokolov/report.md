# ЛР2. Очередь с приоритетом и Top-K

Выполнены 1A, 1B, 1C, 1D и 3A. Код находится в пакете `ru.bmstu.lab2`.

## Очередь

Куча хранится в массиве без пропусков. Родитель всегда имеет приоритет не ниже, чем его дети. По умолчанию в корне минимум. Если передать обратный компаратор, в корне окажется максимум.

| Операция | Время | Объяснение |
| --- | --- | --- |
| `peek`, `size`, `isEmpty` | O(1) | Читаем вершину или счётчик. |
| `add` | O(log n) амортизированно | Вставляем в конец и поднимаем к корню. При заполнении массива одна вставка стоит O(n), но удвоения ёмкости дают O(1) амортизированно на копирование. |
| `poll` | O(log n) | Ставим последний элемент в корень и спускаем максимум на высоту кучи. |
| `remove` | O(n) | Ищем первое совпадение по значению за O(n). Последний элемент переносим на его место и поднимаем или опускаем за O(log n). |
| Конструктор из массива | O(n) | Копируем вход. Начиная с последнего родителя, просеиваем вниз. Около половины узлов являются листьями, четверть проходит максимум один уровень, восьмая часть — два. Сумма работ пропорциональна n. |

Память очереди — O(m), где m — максимальное число одновременно хранившихся элементов. Массив после удалений сохраняет ёмкость, а освобождённые ячейки очищаются.

## Top-K

Держим в min-heap до k лучших элементов. Когда куча заполнена, её вершина — наименьший из отобранных. Очередной элемент заменяет вершину только тогда, когда он больше неё. Так после каждого шага в куче остаются наибольшие из уже просмотренных. Ответ заполняем с конца, чтобы получить порядок по убыванию.

При положительном k обозначим t = min(n, k). Проход по входу и извлечение ответа занимают O(n log(t + 1)) при непустом входе, память — O(t). При k = 1 хватает одного сравнения на элемент. При k ≤ 0 возвращаем пустой список.

## Примеры для ручной проверки

| Вход и действие | Результат | Что проверяет |
| --- | --- | --- |
| Добавить 4, 1, 1. Дважды вызвать `poll()` | 1, 1. В очереди останется 4 | Повторы сохраняются |
| Добавить 1, 10, 2, 11, 12, 3, 4. Удалить 11 | При извлечении получится 1, 2, 3, 4, 10, 12 | Перенесённая 4 должна подняться выше 10 |
| Вызвать `poll()` у пустой очереди | `NoSuchElementException` | Граница размера |
| `topK([5, -1, 5, 3], 3)` | [5, 5, 3] | Отбор с повтором максимума |

## Запуск

Из папки с `pom.xml` на Java 21+ выполнить `mvn clean test`. После тестов замеры в Windows запускаются командой:

```powershell
java -cp "target/classes;target/test-classes" ru.bmstu.lab2.Benchmark
```

В Linux и macOS разделитель путей в этой команде — двоеточие. Результаты приведены в `benchmarks.md`.
