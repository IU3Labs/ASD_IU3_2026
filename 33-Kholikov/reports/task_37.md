# Задача 37. Разворот массива

Лабораторная работа №1 «Массивы». Модуль `33-Kholikov`. Баллы: 2.

## Условие и формат данных

Развернуть массив на месте, без создания нового массива для разворота.

Вводятся размер `n` и `n` целых чисел. Выводится этот массив в обратном порядке.
Размер массива по условию: `1 < n < 100000`, значения элементов имеют тип `int`.

## Идея решения и выбор структуры данных

Два индекса указывают на левый и правый края массива `int[]`.
Элементы меняются местами через одну временную переменную, затем индексы двигаются навстречу.
После обмена очередная внешняя пара уже стоит на окончательных местах.
Когда индексы встретились или пересеклись, разворот закончен.
При нечётной длине средний элемент остаётся на месте.
Массив позволяет менять элементы по индексам; метод `reverse` не создаёт новый массив.

## Время и память

Выполняется `floor(n / 2)` обменов, каждый занимает постоянное время: `O(n)` времени.
Используются два индекса и временная переменная: `O(1)` дополнительной памяти.
Входной массив занимает `O(n)` памяти; чтение и печать требуют `O(n)` времени.
Требование разворота на месте соблюдено: дополнительные массивы в `reverse` не создаются.

Подробный расчёт: [Сложность задачи 37](../asymptotics/task_37.md).

## Примеры проверок

### Пример 1

При нечётной длине средний элемент остаётся на месте.

Ввод:

```text
5
1 2 3 4 5
```

Вывод:

```text
5 4 3 2 1
```

### Пример 2

Разворот массива чётной длины.

Ввод:

```text
4
1 2 3 4
```

Вывод:

```text
4 3 2 1
```

### Пример 3

Минимальная допустимая длина и границы int.

Ввод:

```text
2
-2147483648 2147483647
```

Вывод:

```text
2147483647 -2147483648
```
