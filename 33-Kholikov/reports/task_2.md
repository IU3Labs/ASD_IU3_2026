# Задача 2. Индекс первого вхождения

Лабораторная работа №1 «Массивы». Модуль `33-Kholikov`. Баллы: 1.

## Условие и формат данных

Найти индекс первого элемента, равного числу `x`. Если такого элемента нет, вывести `-1`.

Вводятся размер `n`, затем `n` целых чисел и искомое число `x`. Индексы начинаются с нуля.
Размер массива по условию: `1 < n < 100000`, значения элементов имеют тип `int`.

## Идея решения и выбор структуры данных

Массив `int[]` просматривается слева направо. При первом совпадении метод `firstIndex`
возвращает текущий индекс. Если цикл закончился без совпадений, возвращается `-1`.
До найденного элемента все значения уже проверены, поэтому возвращается именно первое вхождение.
Массив удобен для последовательного обхода и обращения к элементам по индексу.

## Время и память

Если число найдено на индексе `i`, выполняется `i + 1` сравнений.
Лучший случай — совпадение на первом месте: `O(1)`.
Худший случай — последнее место или отсутствие числа: `O(n)`.
Алгоритму достаточно одного индекса, дополнительная память — `O(1)`.
Вместе с чтением и хранением входного массива вся программа требует `O(n)` времени и памяти.

Подробный расчёт: [Сложность задачи 2](../asymptotics/task_2.md).

## Примеры проверок

### Пример 1

Из нескольких совпадений выбирается первое.

Ввод:

```text
5
4 7 2 7 7
7
```

Вывод:

```text
1
```

### Пример 2

Искомого числа нет в массиве.

Ввод:

```text
2
1 2
3
```

Вывод:

```text
-1
```

### Пример 3

Совпадение на первом месте; индексы начинаются с нуля.

Ввод:

```text
2
7 7
7
```

Вывод:

```text
0
```
