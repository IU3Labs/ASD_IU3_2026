# Задача 25. Сумма элементов

Лабораторная работа №1 «Массивы». Модуль `33-Kholikov`. Баллы: 2.

## Условие и формат данных

Вычислить сумму всех элементов целочисленного массива.

Вводятся размер `n` и `n` целых чисел. Выводится их сумма.
Размер массива по условию: `1 < n < 100000`, значения элементов имеют тип `int`.

## Идея решения и выбор структуры данных

В методе `sum` создаётся накопитель `long`, равный нулю. При проходе по массиву `int[]`
к нему прибавляется каждый элемент. После обработки первых `i` элементов накопитель
содержит их сумму; после всего прохода — сумму массива.
Тип `long` нужен, поскольку сумма нескольких значений `int` может выйти за границы `int`.

## Время и память

Выполняются `n` сложений: время — `O(n)`.
Один накопитель занимает `O(1)` дополнительной памяти; память всей программы — `O(n)` из-за входного массива.
При `n <= 99999` модуль суммы не превышает `99999 · 2147483648 = 214746217316352`.
Это значение помещается в `long`.

Подробный расчёт: [Сложность задачи 25](../asymptotics/task_25.md).

## Примеры проверок

### Пример 1

Обычная сумма положительных чисел.

Ввод:

```text
5
10 20 30 40 50
```

Вывод:

```text
150
```

### Пример 2

Ответ не помещается в int, но помещается в long.

Ввод:

```text
2
2147483647 2147483647
```

Вывод:

```text
4294967294
```

### Пример 3

Положительные и отрицательные слагаемые компенсируются.

Ввод:

```text
3
-5 2 3
```

Вывод:

```text
0
```
