# Задача 26. Произведение элементов по модулю

Лабораторная работа №1 «Массивы». Модуль `33-Kholikov`. Баллы: 2.

## Условие и формат данных

Вычислить произведение всех элементов по модулю `M = 1_000_000_007`.

Вводятся размер `n` и `n` целых чисел. Выводится неотрицательный остаток произведения по модулю `M`.
Размер массива по условию: `1 < n < 100000`, значения элементов имеют тип `int`.

## Идея решения и выбор структуры данных

Накопитель начинается с единицы. Каждый элемент массива `int[]` переводится в остаток
из диапазона `[0, M - 1]` через `Math.floorMod`, затем умножается на накопитель.
После умножения снова берётся остаток. Это сохраняет ответ по свойству
`(a · b) mod M = ((a mod M) · (b mod M)) mod M`.
Нормализация нужна для отрицательных чисел. Промежуточное произведение имеет тип `long`.

## Время и память

Массив просматривается один раз; обработка каждого элемента занимает постоянное время: `O(n)`.
Число переменных постоянно, дополнительная память — `O(1)`. С входным массивом — `O(n)`.
Оба множителя меньше `M`, поэтому промежуточное произведение не превышает
`(M - 1)² = 1000000012000000036 < Long.MAX_VALUE`.

Подробный расчёт: [Сложность задачи 26](../asymptotics/task_26.md).

## Примеры проверок

### Пример 1

Обычное произведение.

Ввод:

```text
3
2 3 4
```

Вывод:

```text
24
```

### Пример 2

Отрицательное произведение приводится к неотрицательному остатку.

Ввод:

```text
2
-2 3
```

Вывод:

```text
1000000001
```

### Пример 3

Нулевой множитель обнуляет произведение.

Ввод:

```text
3
3 0 -5
```

Вывод:

```text
0
```
