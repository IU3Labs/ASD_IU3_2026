# Задача 3. Подсчёт вхождений

Лабораторная работа №1 «Массивы». Модуль `33-Kholikov`. Баллы: 1.

## Условие и формат данных

Подсчитать количество элементов массива, равных заданному числу `x`.

Вводятся размер `n`, затем `n` целых чисел и искомое число `x`. Выводится одно число — количество совпадений.
Размер массива по условию: `1 < n < 100000`, значения элементов имеют тип `int`.

## Идея решения и выбор структуры данных

Массив `int[]` перебирается один раз. Счётчик начинается с нуля и увеличивается
при каждом совпадении с `x`. После обработки очередного элемента счётчик равен
количеству совпадений в уже просмотренной части массива. Поэтому после цикла он содержит ответ.
Для последовательного обхода достаточно обычного массива; дополнительные коллекции не нужны.

## Время и память

Цикл проверяет все `n` элементов, на каждом шаге выполняется постоянное число действий: `O(n)` времени.
Счётчик и переменная цикла занимают `O(1)` дополнительной памяти.
С учётом входного массива память всей программы — `O(n)`.
Количество совпадений не превышает `99999`, поэтому для ответа достаточно `int`.

Подробный расчёт: [Сложность задачи 3](../asymptotics/task_3.md).

## Примеры проверок

### Пример 1

Учитываются все совпадения, в том числе на краях массива.

Ввод:

```text
5
7 2 7 4 7
7
```

Вывод:

```text
3
```

### Пример 2

Совпадений нет, счётчик остаётся нулевым.

Ввод:

```text
2
1 2
3
```

Вывод:

```text
0
```

### Пример 3

Отрицательные числа сравниваются так же, как положительные.

Ввод:

```text
4
0 -2 0 -2
-2
```

Вывод:

```text
2
```
