# Задача 35. Префиксные суммы

Лабораторная работа №1 «Массивы». Модуль `33-Kholikov`. Баллы: 2.

## Условие и формат данных

Подготовить префиксные суммы и отвечать на запросы суммы отрезка `[l, r]` за `O(1)` на запрос.

Вводятся размер `n`, элементы массива, количество запросов `q`, затем `q` пар индексов `l r`.
Индексы начинаются с нуля, обе границы включены: `0 <= l <= r < n`. Каждый ответ выводится с новой строки.
Размер массива по условию: `1 < n < 100000`, значения элементов имеют тип `int`.

## Идея решения и выбор структуры данных

Создаётся массив `long[] prefix` длины `n + 1`. Значение `prefix[0]` равно нулю,
а `prefix[i + 1] = prefix[i] + numbers[i]`. Поэтому `prefix[k]` — сумма первых `k` элементов.
Для отрезка `[l, r]` из суммы первых `r + 1` элементов вычитается сумма элементов перед `l`:
`prefix[r + 1] - prefix[l]`. Нулевой префикс позволяет так же обрабатывать отрезки, начинающиеся с нуля.
Вход хранится в `int[]`, префиксы — в `long[]`, так как суммы могут не поместиться в `int`.
Массив префиксов даёт прямой доступ к двум нужным суммам по индексам.

## Время и память

Построение префиксов выполняет `n` сложений: `O(n)`.
В каждом запросе два обращения к массиву и одно вычитание: `O(1)`.
Для `q` запросов полное время — `O(n + q)`.
Префиксы занимают `O(n)` дополнительной памяти. Вся программа также использует `O(n)` памяти:
запросы обрабатываются по одному, без массива запросов.
Суммы при заданной длине массива помещаются в `long`.

Подробный расчёт: [Сложность задачи 35](../asymptotics/task_35.md).

## Примеры проверок

### Пример 1

Проверяются весь массив, отдельные элементы и внутренний отрезок.

Ввод:

```text
5
-5 2 3 7 -1
4
0 4
0 0
1 3
4 4
```

Вывод:

```text
6
-5
12
-1
```

### Пример 2

Ответ не помещается в int.

Ввод:

```text
2
2147483647 2147483647
1
0 1
```

Вывод:

```text
4294967294
```

### Пример 3

При отсутствии запросов программа ничего не выводит.

Ввод:

```text
2
1 2
0
```

Вывод отсутствует.
