# Задача 36. Бегущая сумма

Лабораторная работа №1 «Массивы». Модуль `33-Kholikov`. Баллы: 2.

## Условие и формат данных

Построить массив, где элемент с индексом `i` равен сумме первых `i + 1` элементов исходного массива.

Вводятся размер `n` и `n` целых чисел. Выводятся `n` накопленных сумм через пробел.
Размер массива по условию: `1 < n < 100000`, значения элементов имеют тип `int`.

## Идея решения и выбор структуры данных

Исходные числа хранятся в `int[]`. Создаётся массив результата `long[]` той же длины.
На каждом шаге очередное число прибавляется к накопителю, затем накопитель записывается в результат.
После шага `i` он содержит сумму от `numbers[0]` до `numbers[i]`, то есть нужное значение.
Исходный массив сохраняется. Тип `long` нужен для сумм, превышающих границы `int`.
Массив результата позволяет сохранить сумму для каждой позиции и вывести их по порядку.

## Время и память

Каждый из `n` элементов обрабатывается один раз: `O(n)` времени.
Массив результата требует `O(n)` памяти; кроме него используются только накопитель и индекс — `O(1)`.
Вся программа с входным массивом и результатом занимает `O(n)` памяти.
Печать `n` сумм также занимает `O(n)` времени. Все суммы при заданных ограничениях помещаются в `long`.

Подробный расчёт: [Сложность задачи 36](../asymptotics/task_36.md).

## Примеры проверок

### Пример 1

Проверяется накопление суммы при разных знаках.

Ввод:

```text
5
-5 2 3 7 -1
```

Вывод:

```text
-5 -3 0 7 6
```

### Пример 2

Вторая сумма не помещается в int.

Ввод:

```text
2
2147483647 2147483647
```

Вывод:

```text
2147483647 4294967294
```

### Пример 3

Нулевые элементы сохраняют нулевую сумму.

Ввод:

```text
2
0 0
```

Вывод:

```text
0 0
```
