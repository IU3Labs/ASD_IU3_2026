# Задача 34. Максимальная сумма подмассива

Лабораторная работа №1 «Массивы». Модуль `33-Kholikov`. Баллы: 2.

## Условие и формат данных

Найти максимальную сумму непустого непрерывного подмассива за `O(n)` алгоритмом Кадане.

Вводятся размер `n` и `n` целых чисел. Выводится максимальная сумма непустого подмассива.
Размер массива по условию: `1 < n < 100000`, значения элементов имеют тип `int`.

## Идея решения и выбор структуры данных

`currentSum` хранит максимальную сумму подмассива, который заканчивается на текущем элементе.
Для следующего элемента есть два варианта: начать с него новый подмассив или продолжить предыдущий.
Выбирается `max(numbers[i], currentSum + numbers[i])`.
`bestSum` сохраняет наибольшую сумму среди уже рассмотренных подмассивов.
Обе суммы начинаются с первого элемента, чтобы при всех отрицательных числах ответ не стал нулём.
Для входа используется `int[]`, для сумм — `long`, чтобы избежать переполнения `int`.

## Время и память

После первого элемента выполняются `n - 1` шагов с постоянным числом действий: `O(n)` времени.
Хранятся два накопителя и индекс: `O(1)` дополнительной памяти.
Память всей программы с входным массивом — `O(n)`.
Модуль суммы не превышает `99999 · 2147483648`, что помещается в `long`.

Подробный расчёт: [Сложность задачи 34](../asymptotics/task_34.md).

## Примеры проверок

### Пример 1

Наибольшая сумма у подмассива [4, -1, 2, 1].

Ввод:

```text
9
-2 1 -3 4 -1 2 1 -5 4
```

Вывод:

```text
6
```

### Пример 2

При всех отрицательных значениях выбирается наибольший элемент.

Ввод:

```text
5
-8 -3 -6 -2 -5
```

Вывод:

```text
-2
```

### Пример 3

Сумма подмассива может выйти за границы int.

Ввод:

```text
2
2147483647 2147483647
```

Вывод:

```text
4294967294
```
