# Расчёт сложности задачи 37. Разворот массива

`n` — число элементов массива.
По условию `1 < n < 100000`, входные элементы имеют тип `int`.
Дополнительная память указана без входного массива. Операции над `int` и `long` считаются постоянными.

## Время алгоритма

Два индекса двигаются от краёв к середине. На каждом шаге выполняется один обмен.
Число обменов равно `floor(n / 2)`, каждый занимает постоянное время:
`T(n) = c₁ floor(n / 2) + c₂ = Θ(n)`.
После обмена очередная внешняя пара находится на окончательных местах.
При нечётной длине средний элемент остаётся на месте.

## Память

Метод `reverse` использует два индекса и одну временную переменную: `Θ(1)` дополнительной памяти.
Новый массив для разворота не создаётся — требование изменения на месте выполнено.
Входной массив занимает `Θ(n)` памяти; это же оценка памяти всей программы.

## С учётом ввода и вывода

Чтение и печать массива требуют `Θ(n)` времени.
Вывод выполняется по одному элементу, дополнительный массив для него не создаётся.
Полное время программы — `Θ(n)`.

## Числовые границы

Значения элементов только переставляются, арифметические действия над ними не выполняются.
Поэтому крайние значения `int` сохраняются без переполнения. Индексы при `n <= 99999` также помещаются в `int`.
