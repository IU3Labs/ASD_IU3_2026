# Расчёт сложности задачи 36. Бегущая сумма

`n` — число элементов массива.
По условию `1 < n < 100000`, входные элементы имеют тип `int`.
Дополнительная память указана без входного массива. Операции над `int` и `long` считаются постоянными.

## Время алгоритма

Каждый из `n` элементов один раз прибавляется к накопителю;
полученная сумма записывается в результат. На шаге выполняется постоянное число действий:
`T(n) = c₁n + c₂ = Θ(n)`.
После шага `i` накопитель и `result[i]` равны сумме `numbers[0] ... numbers[i]`.

## Память

Результат содержит `n` значений `long`, поэтому дополнительная память вместе с результатом — `Θ(n)`.
Если не учитывать результат, остаются накопитель и индекс: `Θ(1)`.
Вся программа с входным массивом и результатом использует `Θ(n)` памяти.
Исходный массив не изменяется.

## С учётом ввода и вывода

Чтение массива и печать `n` накопленных сумм требуют `Θ(n)` времени.
Полное время программы остаётся `Θ(n)`.

## Числовые границы

При заданных ограничениях модуль любой суммы не превышает
`99999 · 2147483648 = 214746217316352 < Long.MAX_VALUE`.
Поэтому суммы хранятся в `long`, входные значения — в `int`.
