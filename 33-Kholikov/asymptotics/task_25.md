# Расчёт сложности задачи 25. Сумма элементов

`n` — число элементов массива.
По условию `1 < n < 100000`, входные элементы имеют тип `int`.
Дополнительная память указана без входного массива. Операции над `int` и `long` считаются постоянными.

## Время алгоритма

Каждый из `n` элементов один раз прибавляется к накопителю.
Число сложений равно `n`: `T(n) = c₁n + c₂ = Θ(n)`.
После обработки первых `i` элементов накопитель содержит их сумму.

## Память

Один накопитель `long` и переменная цикла занимают `Θ(1)` дополнительной памяти.
Для входного массива требуется `Θ(n)` памяти; вся программа также использует `Θ(n)`.

## С учётом ввода и вывода

Чтение массива занимает `Θ(n)` времени, вывод одной суммы — `Θ(1)`.
Полное время программы — `Θ(n)`.

## Числовые границы

При заданных ограничениях модуль любой суммы не превышает
`99999 · 2147483648 = 214746217316352 < Long.MAX_VALUE`.
Поэтому суммы хранятся в `long`, входные значения — в `int`.
