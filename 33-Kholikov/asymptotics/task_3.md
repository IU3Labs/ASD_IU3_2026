# Расчёт сложности задачи 3. Подсчёт вхождений

`n` — число элементов массива.
По условию `1 < n < 100000`, входные элементы имеют тип `int`.
Дополнительная память указана без входного массива. Операции над `int` и `long` считаются постоянными.

## Время алгоритма

Цикл выполняет `n` сравнений с искомым числом и не более `n` увеличений счётчика.
Каждый шаг занимает постоянное время: `T(n) = c₁n + c₂ = Θ(n)`.
После обработки первых `i` элементов счётчик равен числу совпадений среди них.
После последнего шага он содержит ответ для всего массива.

## Память

Счётчик, текущий элемент и искомое число занимают `Θ(1)` дополнительной памяти.
Входной массив и вся программа требуют `Θ(n)` памяти.

## С учётом ввода и вывода

Чтение `n` чисел занимает `Θ(n)` времени, вывод одного счётчика — `Θ(1)`.
Полное время программы остаётся `Θ(n)`.

## Числовые границы

Количество совпадений находится в `[0, n]`, причём `n <= 99999`.
Поэтому счётчик помещается в `int`. Значения элементов только сравниваются, арифметика над ними не выполняется.
