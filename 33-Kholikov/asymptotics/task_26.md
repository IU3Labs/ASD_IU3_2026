# Расчёт сложности задачи 26. Произведение элементов по модулю

`n` — число элементов массива.
По условию `1 < n < 100000`, входные элементы имеют тип `int`.
Дополнительная память указана без входного массива. Операции над `int` и `long` считаются постоянными.

## Время алгоритма

На каждом из `n` шагов вычисляется неотрицательный остаток элемента,
затем выполняются умножение и взятие остатка по модулю `M = 1_000_000_007`.
Для фиксированных типов Java эти действия занимают постоянное время:
`T(n) = c₁n + c₂ = Θ(n)`.
По свойству `(a · b) mod M = ((a mod M) · (b mod M)) mod M`
накопитель содержит остаток произведения уже обработанных элементов.

## Память

Накопитель, нормализованный остаток и текущий элемент требуют `Θ(1)` дополнительной памяти.
С учётом входного массива память всей программы — `Θ(n)`.

## С учётом ввода и вывода

Чтение массива занимает `Θ(n)` времени, вывод одного остатка — `Θ(1)`.
Полное время программы остаётся `Θ(n)`.

## Числовые границы

`Math.floorMod` переводит каждый элемент в `[0, M - 1]`, включая отрицательные числа.
Оба множителя перед умножением меньше `M`. Максимальное промежуточное произведение:
`(M - 1)² = 1000000012000000036 < Long.MAX_VALUE`.
Умножение выполняется в `long`, поэтому переполнения нет.
