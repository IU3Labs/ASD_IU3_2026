# Расчёт сложности задачи 34. Максимальная сумма подмассива

`n` — число элементов массива.
По условию `1 < n < 100000`, входные элементы имеют тип `int`.
Дополнительная память указана без входного массива. Операции над `int` и `long` считаются постоянными.

## Время алгоритма

Первый элемент задаёт начальные суммы. Для остальных выполняется `n - 1` шагов.
На каждом шаге вычисляются сумма и два максимума:
`T(n) = c₁(n - 1) + c₂ = Θ(n)`. Это соответствует требованию алгоритма Кадане.
`currentSum` — лучшая сумма непустого подмассива, заканчивающегося в текущей позиции.
Переход: `currentSum = max(numbers[i], currentSum + numbers[i])`.
`bestSum` хранит максимум среди всех уже рассмотренных концов подмассива.
Начало с первого элемента сохраняет правильный ответ при всех отрицательных числах.

## Память

Два накопителя `long` и индекс занимают `Θ(1)` дополнительной памяти.
Входной массив занимает `Θ(n)`, поэтому память всей программы — `Θ(n)`.

## С учётом ввода и вывода

Чтение `n` чисел занимает `Θ(n)` времени, вывод одной суммы — `Θ(1)`.
Полное время программы — `Θ(n)`.

## Числовые границы

При заданных ограничениях модуль любой суммы не превышает
`99999 · 2147483648 = 214746217316352 < Long.MAX_VALUE`.
Поэтому суммы хранятся в `long`, входные значения — в `int`.
