# Расчёт сложности задачи 2. Индекс первого вхождения

`n` — число элементов массива.
По условию `1 < n < 100000`, входные элементы имеют тип `int`.
Дополнительная память указана без входного массива. Операции над `int` и `long` считаются постоянными.

## Время алгоритма

Если первое совпадение находится на индексе `i`, выполняется `i + 1` сравнений.
`T(n, i) = c₁(i + 1) + c₂`. При совпадении в начале время — `Θ(1)`.
В худшем случае число находится в конце или отсутствует: проверяются все `n` элементов, время — `Θ(n)`.
Поиск идёт слева направо, поэтому первое найденное совпадение имеет наименьший индекс.

## Память

Метод `firstIndex` использует только индекс и искомое число: `Θ(1)` дополнительной памяти.
Входной массив занимает `Θ(n)` памяти, вся программа — `Θ(n)`.

## С учётом ввода и вывода

Массив полностью читается перед поиском. Поэтому даже при совпадении на первом месте
время всей программы с вводом — `Θ(n)`. Вывод одного индекса занимает `Θ(1)`.

## Числовые границы

При `n <= 99999` допустимые индексы лежат в `[0, 99998]`.
Индекс и значение `-1` для отсутствующего числа помещаются в `int`.
Числа сравниваются напрямую, без вычитания, поэтому крайние значения `int` не вызывают переполнения.
