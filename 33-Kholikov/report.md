# Отчёт по лабораторной работе №2

**Холиков С. В., группа 33Б**

**Тема** — структуры данных

**Задачи** — 1A, 1C, 1D и 2A, всего 9 баллов по таблице заданий

## Решение

**1A — очередь с приоритетом.** Двоичная min-куча хранится в расширяемом массиве. Минимум находится в корне. При вставке новый элемент поднимается до восстановления порядка. При извлечении минимума последний элемент занимает место корня и опускается, меняясь местами с меньшим ребёнком. Массив даёт доступ к родителю и детям по индексам и позволяет хранить кучу без отдельных объектов для узлов.

**1C — удаление из очереди по значению.** `remove` проходит по массиву и находит первое совпадение по `equals`. На его место переносится последний элемент. Если он меньше родителя, вызывается `siftUp`, иначе — `siftDown`. При удалении последнего элемента достаточно очистить его ячейку.

**1D — построение кучи из массива.** Конструктор `PriorityQueueCustom(T[] array)` проверяет элементы, копирует массив и вызывает `siftDown` для внутренних узлов от последнего к корню. Когда обрабатывается узел, поддеревья его детей уже являются кучами. Листья просеивать не нужно, а большинство внутренних узлов опускается лишь на несколько уровней. Исходный массив сохраняет порядок элементов и может использоваться независимо от очереди.

**2A — хеш-таблица.** `HashMapCustom` хранит ключи и значения в двух массивах. При совпадении начальных индексов поиск идёт по соседним ячейкам с переходом от конца массива к началу. Маркер `DELETED` сохраняет цепочку поиска. Вставка запоминает первую удалённую ячейку и продолжает поиск ключа, чтобы обновить существующую запись. При превышении 75% живых записей ёмкость удваивается. Если число занятых ячеек вместе с маркерами превысило бы 87,5%, маркеры очищаются перехешированием с сохранением ёмкости. Значение `null` поддерживается, а наличие записи проверяется через `containsKey`.

## Сложность и проверка

Для очереди `add` работает за амортизированное `O(log n)`, `poll` за `O(log n)`, удаление по значению и построение из массива за `O(n)`, а `peek`, `size` и `isEmpty` за `O(1)`. Для хеш-таблицы `get`, `containsKey` и `remove` работают в среднем за `O(1)` при равномерном распределении хешей, а `put` — амортизированно в среднем за `O(1)`. Обе структуры используют `O(C)` памяти, где `C` — текущая ёмкость. [Подробный расчёт](ASYMPTOTICS.md) · [Замеры](benchmarks.md)

### Примеры ручной проверки

| Задача | Действия | Ожидаемый результат и смысл проверки |
|---|---|---|
| 1A | Добавить `8, 3, 3, 5`. Вызвать `peek`, четыре раза `poll`, затем ещё раз `poll`. | `peek` возвращает `3`. Первые четыре извлечения дают `3, 3, 5, 8`. Последний вызов выбрасывает `NoSuchElementException`. Проверяются порядок, дубликаты и пустая очередь. |
| 1C | Добавить `1, 2, 3, 4, 5, 6, 7, 8`. Вызвать `remove(2)` и `remove(20)`, затем извлечь оставшиеся элементы. | Вызовы дают `true` и `false`. Извлечение даёт `1, 3, 4, 5, 6, 7, 8`. Проверяются удаление внутреннего узла и восстановление кучи. |
| 1D | Построить очередь из массива `{8, 1, 4}`. Проверить массив, затем присвоить первым двум ячейкам `-5` и `-7` и извлечь элементы очереди. | Сразу после построения массив содержит `{8, 1, 4}`. Очередь выдаёт `1, 4, 8`. Проверяются порядок извлечения и независимость копии. |
| 2A | При начальной ёмкости 16 вставить ключи `15, 31, 47` со значениями `A, B, C`. Удалить `15`, прочитать `31` и `47`, обновить `47` до `D`. | `get(15)` возвращает `null`, `get(31)` — `B`, `get(47)` после обновления — `D`. Размер остаётся `2` после обновления. Проверяются коллизия, переход через границу массива и поиск через `DELETED`. |
| 2A | В новой таблице вставить ключи `0…11`, обновить ключ `0`, затем добавить ключ `12`. | После обновления размер равен `12`, ёмкость `16`. После новой вставки размер `13`, ёмкость `32`. Все значения доступны. Проверяются граница загрузки и перехеширование. |

Проверка `mvn clean verify` прошла успешно. Для очереди написано 28 тестов JUnit 5, для хеш-таблицы — 14. В тестах проверяются граничные случаи и последовательности вставок, поисков и удалений со сравнением результатов с `java.util.PriorityQueue` и `java.util.HashMap`.
