# Задача 25. Сумма элементов

## Идея решения

Программа читает числа в массив.
Затем проходит по массиву и прибавляет каждый элемент к сумме.
Для хранения суммы используется long.

## Сложность

Время: O(n), потому что каждый элемент обрабатывается
постоянное количество раз.

Память: O(n), потому что программа хранит массив из n элементов.
Дополнительная память при подсчёте суммы: O(1).

## Ручные проверки

- Положительные числа: 10 20 30 40 50 → 150.
- Числа разных знаков: -5 2 3 → 0.
- Нулевые элементы: 0 0 0 0 → 0.
- Большая сумма: 2000000000 2000000000 → 4000000000.
