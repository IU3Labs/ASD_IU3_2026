# Лабораторная работа №1 — массивы

Модуль: `33-Kholikov`. Ветка: `lab01-Kholikov-33`.

## Выполненные задачи

| № | Задача | Баллы |
|---|---|---|
| 2 | Индекс первого вхождения | 1 |
| 3 | Подсчёт вхождений | 1 |
| 25 | Сумма элементов | 2 |
| 26 | Произведение по модулю | 2 |
| 34 | Максимальная сумма подмассива | 2 |
| 35 | Префиксные суммы | 2 |

## Как устроены решения

Для входных данных используется `int[]`: элементы удобно перебирать по порядку и менять по индексу.
Общее чтение и печать вынесены в `ArrayIo`, чтобы не повторять этот код в каждой задаче.
Для сумм используется `long`, так как сумма нескольких значений `int` может не поместиться в `int`.

- **2:** перебираем элементы слева направо. При первом совпадении возвращаем индекс,
  иначе после цикла возвращаем `-1`.
- **3:** считаем совпадения с заданным числом за один проход.
- **25:** прибавляем каждый элемент к общей сумме.
- **26:** после каждого умножения берём остаток по модулю `1_000_000_007`.
  `Math.floorMod` переводит отрицательные числа в неотрицательные остатки.
- **34:** алгоритм Кадане. На каждом шаге выбираем: начать подмассив с текущего числа
  или продолжить предыдущий. Начинаем с первого элемента, чтобы правильно обработать отрицательный массив.
- **35:** сначала строим префиксные суммы. Ответ для `[l, r]` получаем как `prefix[r + 1] - prefix[l]`.
- **36:** накапливаем сумму и записываем её после каждого шага в новый массив `long[]`.
- **37:** меняем местами элементы с краёв массива и двигаемся к середине.
  Разворот выполняется в исходном массиве.

## Время и память

Задачи 2, 3, 25, 26, 34, 36 и 37 работают за `O(n)` в худшем случае.
В задаче 2 поиск может закончиться на первом элементе за `O(1)`.
В задаче 35 подготовка занимает `O(n)`, один запрос — `O(1)`, всего — `O(n + q)`.

Алгоритмы 2, 3, 25, 26, 34 и 37 используют `O(1)` дополнительной памяти.
Префиксы задачи 35 и результат задачи 36 занимают `O(n)`.
С учётом хранения входного массива память каждой программы — `O(n)`.
Подробный расчёт: [ASYMPTOTICS.md](ASYMPTOTICS.md).

## Ввод и вывод

Сначала вводятся размер `n` и `n` целых чисел. В задачах 2 и 3 затем вводится искомое число `x`.
В задаче 35 после массива вводятся количество запросов `q` и пары индексов `l r`.
Индексы начинаются с нуля, обе границы отрезка включены: `0 <= l <= r < n`.
По условию `1 < n < 100000`. Входные числа имеют тип `int`.
Ответ выводится без приглашений к вводу; элементы массива разделяются пробелами.
