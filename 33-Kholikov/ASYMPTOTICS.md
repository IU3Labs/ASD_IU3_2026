# Расчёт асимптотики лабораторной №1

`n` — число элементов массива, `q` — число запросов задачи 35.
В таблице дополнительная память не включает уже прочитанный входной массив.
Все решения используют только стандартную библиотеку Java.

| Задача | Время алгоритма | Дополнительная память | Память всей программы |
|---|---|---|---|
| 2 — первое вхождение | O(n), лучший случай Θ(1), худший Θ(n) | Θ(1) | Θ(n) |
| 3 — подсчёт вхождений | Θ(n) | Θ(1) | Θ(n) |
| 25 — сумма | Θ(n) | Θ(1) | Θ(n) |
| 26 — произведение по модулю | Θ(n) | Θ(1) | Θ(n) |
| 34 — максимальная сумма подмассива | Θ(n) | Θ(1) | Θ(n) |
| 35 — префиксные суммы | Θ(n) подготовка, Θ(1) запрос, Θ(n + q) всего | Θ(n) | Θ(n) |
| 36 — бегущая сумма | Θ(n) | Θ(n) для результата, Θ(1) кроме результата | Θ(n) |
| 37 — разворот на месте | Θ(n) | Θ(1) | Θ(n) |

## 2. Индекс первого вхождения

Просматриваем элементы слева направо. До текущего индекса совпадений нет;
поэтому первое найденное совпадение имеет наименьший индекс.
Если цикл закончился без совпадений, возвращается `-1`.
При совпадении на индексе `i` выполняется `i + 1` сравнений.
Лучший случай — первое место: Θ(1). Худший — последнее место или отсутствие числа: Θ(n).
Дополнительная память — Θ(1): используются только индекс и искомое число.
Вся программа с чтением массива требует Θ(n) времени и Θ(n) памяти.

## 3. Подсчёт вхождений

После обработки первых `i` элементов счётчик равен количеству совпадений среди них.
Каждый следующий элемент либо увеличивает счётчик на один, либо оставляет его прежним.
После прохода счётчик содержит число совпадений во всём массиве.
Проверяются все `n` элементов: `T(n) = c₁n + c₂ = Θ(n)`.
Один счётчик и переменная цикла занимают Θ(1) дополнительной памяти.
Ответ не превышает `99999`, поэтому помещается в `int`.
С учётом хранения входного массива вся программа использует Θ(n) памяти.

## 25. Сумма

Цикл выполняется `n` раз; на каждом шаге выполняется одно сложение.
`T(n) = c₁n + c₂ = Θ(n)`. Хранится один накопитель `long`.
После обработки первых `i` элементов накопитель равен их сумме — это инвариант цикла.

## 26. Произведение по модулю

На каждом из `n` шагов нормализуем элемент по модулю `M = 1_000_000_007`,
умножаем накопитель на остаток и снова берём остаток.
`T(n) = c₁n + c₂ = Θ(n)`; число переменных постоянно.
По свойству `(a · b) mod M = ((a mod M) · (b mod M)) mod M`
накопитель всегда равен остатку произведения уже обработанных элементов.
`Math.floorMod` даёт остаток в `[0, M - 1]`, включая отрицательные исходные числа.

## 34. Алгоритм Кадане

`currentSum` — максимальная сумма непустого подмассива, заканчивающегося в текущей позиции.
Такой подмассив либо состоит из текущего элемента, либо продолжает предыдущий:
`currentSum = max(a[i], currentSum + a[i])`.
`bestSum` хранит максимум среди всех уже рассмотренных концов подмассива.
Инициализация первым элементом сохраняет непустой ответ при всех отрицательных числах.
Выполняется `n - 1` шагов с постоянным числом операций: `Θ(n)` времени, `Θ(1)` памяти.

## 35. Префиксные суммы

В массиве длины `n + 1` храним `prefix[0] = 0` и
`prefix[i + 1] = prefix[i] + a[i]`. Построение: `n` сложений, то есть `Θ(n)`.
Для включительного отрезка `[l, r]` ответ равен `prefix[r + 1] - prefix[l]`:
из суммы первых `r + 1` элементов вычитаются элементы перед `l`.
Каждый запрос требует `Θ(1)`, все `q` запросов вместе с подготовкой — `Θ(n + q)`.
Память для префиксов — `Θ(n)`. Запросы читаются и выводятся по одному, без массива запросов.

## 36. Бегущая сумма

После шага `i` накопитель равен сумме `a[0] ... a[i]`, это значение записывается в результат.
Цикл выполняется `n` раз: `Θ(n)` времени. Результат содержит `n` значений `long`: `Θ(n)` памяти.
Кроме результата используется один накопитель и индекс: `Θ(1)` памяти.
Исходный массив не изменяется.

## 37. Разворот на месте

Меняем местами крайние ещё не обработанные элементы и двигаем два индекса навстречу.
После каждого обмена соответствующая внешняя пара стоит на окончательных местах.
Выполняется `floor(n / 2)` обменов: `Θ(n)` времени.
При нечётной длине средний элемент остаётся на месте.
Используются два индекса и одна временная переменная: `Θ(1)` дополнительной памяти.
В методе `reverse` новые массивы не создаются.

## Числовые границы и ввод-вывод

По условию `1 < n < 100000`. Для входных значений Java `int` модуль суммы не превышает
`99999 · 2147483648 = 214746217316352`, что помещается в `long`.
Это относится к сумме, префиксам, бегущим суммам и суммам подмассивов.
При вычислении произведения оба множителя после нормализации меньше `M`,
поэтому промежуточное произведение не превышает `(M - 1)² = 1000000012000000036 < Long.MAX_VALUE`.

Чтение массива занимает `Θ(n)` памяти и времени при ограниченной длине записи `int`.
Печать массивов в задачах 36 и 37 занимает `Θ(n)` времени и не создаёт дополнительного массива.
Таким образом, полный ввод-вывод не ухудшает заявленные оценки.
