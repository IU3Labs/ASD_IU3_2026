# Отчет по задаче 15: Пузырьковая сортировка с подсчётом обменов

## 1. Идея решения и структура данных
**Идея:** Алгоритм многократно проходит по массиву слева направо. На каждом проходе сравниваются соседние элементы. Если левый элемент больше правого, они меняются местами (инкрементируется счетчик обменов). Таким образом, за один проход наибольший элемент «всплывает» в конец массива. Для оптимизации введен флаг `swapped`: если за весь проход не было ни одного обмена, массив уже отсортирован, и происходит досрочный выход.

**Структура данных:** Базовый массив `int[]`. Размер массива считывается из входного потока. Массив позволяет обращаться к элементам по индексу за $O(1)$ и производить перестановки. Дополнительно используется счетчик `swaps` для подсчета инверсий.

## 2. Анализ асимптотики
**Временная сложность: $O(n^2)$ в худшем случае, $O(n)$ в лучшем**

Обоснование на основе кода:
```java
for (int i = 0; i < arr.length - 1; i++) {
    swapped = false;
    for (int j = 0; j < arr.length - 1 - i; j++) {
        if (arr[j] > arr[j + 1]) {
            // обмен и увеличение счетчика swaps
            swapped = true;
        }
    }
    if (!swapped) break;
}
```
В худшем случае (массив отсортирован по убыванию) внутренний цикл выполнится $(n-1) + (n-2) + ... + 1$ раз суммарно, что дает общую сложность $O(n^2)$. В лучшем случае (массив уже отсортирован по неубыванию) внешний цикл выполнится один раз, ни одного обмена не произойдет, сработает условие `if (!swapped) break;`, и алгоритм завершит работу за время $O(n)$.

**Дополнительная память: $O(1)$**
Дополнительная память не зависит от размера массива $n$. Используются только локальные переменные `i`, `j`, буфер `t` для обмена элементов, счетчик `swaps` и флаг `swapped`.

## 3. Ручные тесты
1. **Лучший случай: массив уже отсортирован**
   - *Вход:* `5 | 1 2 3 4 5`
   - *Выход:* `1 2 3 4 5 \n 0`
   - *Значимость:* Проверяет досрочный выход (флаг `swapped`). Цикл прерывается после первого прохода, счетчик обменов равен 0.
2. **Худший случай: массив отсортирован по убыванию**
   - *Вход:* `5 | 5 4 3 2 1`
   - *Выход:* `1 2 3 4 5 \n 10`
   - *Значимость:* Гарантирует, что алгоритм корректно отрабатывает максимальное количество раз. Максимальное число обменов вычисляется по формуле $n(n-1)/2$.
3. **Массив с отрицательными числами и дубликатами**
   - *Вход:* `6 | -1 0 -1 5 5 -10`
   - *Выход:* `-10 -1 -1 0 5 5 \n 6`
   - *Значимость:* Проверяет, что строгое неравенство `arr[j] > arr[j+1]` сохраняет стабильность сортировки (одинаковые элементы не меняются местами) и корректно работает со знаками.
