# Отчет по задаче 14: Сортировка вставками (Insertion Sort)

## 1. Идея решения и структура данных
**Идея:** Алгоритм проходит по массиву слева направо, начиная со второго элемента. На каждом шаге берется текущий элемент (ключ) и вставляется на правильную позицию в уже отсортированную левую часть. Так как по условию требуется сортировка по невозрастанию, сдвигаем вправо все элементы, которые меньше ключа.

**Структура данных:** Базовый массив `int[]`. Размер массива считывается из входного потока, а сам массив позволяет обращаться к элементам по индексу за $O(1)$ и производить модификацию (сдвиги).

## 2. Анализ асимптотики
**Временная сложность: $O(n^2)$ в худшем случае, $O(n)$ в лучшем**

Обоснование на основе кода:
```java
for (int i = 1; i < arr.length; i++) {
    int key = arr[i];
    int j = i - 1;
    while (j >= 0 && arr[j] < key) {
        arr[j + 1] = arr[j];
        j--;
    }
}
```
Внешний цикл выполняется строго $n - 1$ раз. Внутренний цикл `while` зависит от исходных данных. В худшем случае (массив отсортирован по возрастанию) внутренний цикл сделает $i$ итераций, что в сумме даст арифметическую прогрессию и сложность $O(n^2)$. В лучшем случае (массив уже отсортирован по убыванию) условие `arr[j] < key` сразу вернет `false`, внутренний цикл не выполнится ни разу, и сложность составит $O(n)$.

**Дополнительная память: $O(1)$**
Дополнительная память не зависит от размера массива $n$. Используются только локальные переменные `i`, `j` и буфер `key` для хранения вставляемого элемента.

## 3. Ручные тесты
1. **Худший случай: массив отсортирован по неубыванию**
   - *Вход:* `5 | 1 2 3 4 5`
   - *Выход:* `5 4 3 2 1`
   - *Значимость:* Гарантирует, что алгоритм корректно отрабатывает максимальное количество раз
2. **Лучший случай: массив уже отсортирован по невозрастанию**
   - *Вход:* `5 | 5 4 3 2 1`
   - *Выход:* `5 4 3 2 1`
   - *Значимость:* Проверяет условие `arr[j] < key` — алгоритм должен отработать эффективно: элементы не должны перезаписываться, цикл `while` не должен запускаться.
3. **Массив с отрицательными числами и дубликатами**
   - *Вход:* `5 | -5 2 -10 0 2`
   - *Выход:* `2 2 0 -5 -10`
   - *Значимость:* Проверяет работу со знаками и гарантирует, что строгое неравенство `arr[j] < key` сохраняет относительный порядок одинаковых элементов.
