# Отчет по задаче 16: Сортировка по модулю

## 1. Идея решения и структура данных
**Идея:** Алгоритм быстрой сортировки (QuickSort) рекурсивно разбивает массив на две части относительно опорного элемента (`pivot`). Все элементы, меньше опорного, перемещаются влево, а больше — вправо. Затем сортировка применяется к левой и правой частям. Сравнение элементов производится по их модулю. Если модули равны, отрицательное число считается меньшим и помещается перед положительным.

**Структура данных:** Базовый массив `int[]`. Размер массива считывается из входного потока. Массив позволяет обращаться к элементам по индексу за $O(1)$ и производить перестановки.

## 2. Анализ асимптотики
**Временная сложность: $O(n \log n)$ в среднем случае, $O(n^2)$ в худшем**

Обоснование на основе кода:
```java
while (i <= j) {
    while (lessThan(arr[i], pivot)) {
        i++;
    }
    while (lessThan(pivot, arr[j])) {
        j--;
    }
    if (i <= j) {
        // swap i and j
    }
}
if (left < j) quickSortByAbs(arr, left, j);
if (i < right) quickSortByAbs(arr, i, right);
```
На каждом уровне рекурсии алгоритм просматривает все элементы текущего подмассива (суммарно $n$ операций). В среднем случае опорный элемент делит массив примерно пополам, поэтому глубина рекурсии составляет $\log n$. В итоге средняя сложность $O(n \log n)$. Худший случай $O(n^2)$ возможен, если при каждом разделении опорный элемент оказывается наименьшим или наибольшим в массиве.

**Дополнительная память: $O(\log n)$ в среднем, $O(n)$ в худшем**
Алгоритм сортирует элементы in-place, поэтому дополнительная память для данных не требуется ($O(1)$). Однако рекурсивные вызовы используют стек вызовов. В среднем случае глубина рекурсии $\log n$, что требует $O(\log n)$ памяти. В худшем случае (когда массив делится на $1$ и $n-1$ элементов) глубина рекурсии достигает $n$, и требуется $O(n)$ памяти.

## 3. Ручные тесты
1. **Массив с разными по модулю числами**
   - *Вход:* `6 | -4 1 5 -1 0 4`
   - *Выход:* `0 -1 1 -4 4 5`
   - *Значимость:* Проверяет базовую логику сортировки по модулю.
2. **Массив с одинаковыми по модулю числами**
   - *Вход:* `6 | 5 -5 2 -2 5 -5`
   - *Выход:* `-2 2 -5 -5 5 5`
   - *Значимость:* Гарантирует корректную работу второго условия `lessThan`: при равных модулях отрицательное число всегда предшествует положительному.
3. **Худший/лучший случай: массив уже отсортирован**
   - *Вход:* `5 | 0 -1 1 -2 2`
   - *Выход:* `0 -1 1 -2 2`
   - *Значимость:* Проверяет работу алгоритма при выборе центрального элемента (`pivot`) в отсортированном массиве, что влияет на эффективность разделения.
