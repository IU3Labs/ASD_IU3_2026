# Отчет по задаче 13: Сортировка выбором (Selection Sort)

## 1. Идея решения и структура данных
**Идея:** Массив визуально делится на отсортированную (левую) и неотсортированную (правую) части. На каждом шаге алгоритм ищет минимальный элемент в правой части и меняет его местами с первым элементом этой части.

**Структура данных:** Базовый массив `int[]`. Размер массива считывается из входного потока, а сам массив позволяет обращаться к элементам по индексу за $O(1)$, что необходимо для быстрой перестановки элементов.

## 2. Анализ асимптотики
**Временная сложность: $O(n^2)$**

Обоснование на основе кода:
```java
for (int i = 0; i < arr.length - 1; i++) {
    int min = i;
    for (int j = i + 1; j < arr.length; j++) {
        if (arr[j] < arr[min]) {
            min = j; 
        }
    }
}
```
В алгоритме используются два вложенных цикла. Внешний цикл выполняется $n - 1$ раз. Внутренний цикл на каждом шаге `i` выполняет $(n - 1 - i)$ итераций. Общее количество операций сравнения равно сумме арифметической прогрессии: $(n-1) + (n-2) + ... + 1$. Отбрасывая константы и младшие члены, получаем строгую сложность $O(n^2)$ во всех случаях.

**Дополнительная память: $O(1)$**

Дополнительная память не зависит от размера массива $n$ и используется только для хранения нескольких локальных переменных (`i`, `j`, `min`) и буфера `t` для обмена элементов.

## 3. Интересные технические решения
Для предотвращения появления "пробела" в конце строки вывода (что вызывает ошибки формата в тестах) использован функциональный подход через Stream API:
```java
out.println(Arrays.stream(arr)
                .mapToObj(String::valueOf)
                .collect(Collectors.joining(" ")));
```

## 4. Ручные тесты
1. **Массив с дубликатами и отрицательными числами**
   - *Вход:* `6 | 5 -2 5 0 -10 3`
   - *Выход:* `-10 -2 0 3 5 5`
   - *Значимость:* Проверяет работу строгого неравенства при поиске минимума и гарантирует, что алгоритм правильно работает при наличии одинаковых значений.
2. **Обратно отсортированный массив (худший случай для перестановок)**
   - *Вход:* `5 | 9 7 5 3 1`
   - *Выход:* `1 3 5 7 9`
   - *Значимость:* Гарантирует, что алгоритм корректно отрабатывает максимальное количество раз.
3. **Уже отсортированный массив (лучший случай)**
   - *Вход:* `4 | 1 2 3 4`
   - *Выход:* `1 2 3 4`
   - *Значимость:* Проверяет условие `if (min != i)` — алгоритм должен отработать все вложенные циклы для проверки, но ни разу не выполнить перезапись ячеек памяти.
