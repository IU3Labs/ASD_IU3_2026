# Отчет по задаче 18: Сортировка только чётных

## 1. Идея решения и структура данных
**Идея:** Алгоритм проходит по исходному массиву и собирает все чётные элементы во временный массив. Затем этот временный массив сортируется по неубыванию с помощью нашей ручной быстрой сортировки (QuickSort). На финальном этапе алгоритм снова проходит по исходному массиву и заменяет чётные элементы на отсортированные из временного массива, оставляя нечётные элементы на своих исходных позициях.

**Структура данных:** Базовый массив `int[]`. Для хранения чётных элементов выделяется дополнительный массив `evens` размера $k$, где $k$ — количество чётных чисел в исходном массиве.

## 2. Анализ асимптотики
**Временная сложность: $O(n \log n)$ в среднем случае, $O(n^2)$ в худшем**

Обоснование на основе кода:
```java
// 1. Выделение чётных элементов — O(n)
for (int num : arr) {
    if (num % 2 == 0) {
        evens[index++] = num;
    }
}

// 2. Быстрая сортировка массива evens размера k (k <= n) — O(k log k)
quickSort(evens, 0, evens.length - 1);

// 3. Возврат элементов на свои места — O(n)
for (int i = 0; i < arr.length; i++) {
    if (arr[i] % 2 == 0) {
        arr[i] = evens[index++];
    }
}
```
Алгоритм выполняет два независимых линейных прохода по исходному массиву длины $n$, что дает $O(n)$. Сортировка массива `evens` размера $k$ с помощью QuickSort занимает в среднем $O(k \log k)$ времени. Так как $k \le n$, итоговая сложность определяется самым тяжелым этапом (сортировкой) и составляет $O(n \log n)$.

**Дополнительная память: $O(n)$**
Создается временный массив `evens`, размер которого в худшем случае (если все элементы чётные) равен размеру исходного массива $n$. Кроме того, рекурсивные вызовы QuickSort требуют $O(\log n)$ памяти на стеке. Итоговая дополнительная память составляет $O(n)$.

## 3. Ручные тесты
1. **Массив без чётных элементов**
   - *Вход:* `3 | 1 3 5`
   - *Выход:* `1 3 5`
   - *Значимость:* Проверяет досрочный выход `if (evenCount <= 1)`. Гарантирует, что алгоритм не выделяет лишнюю память и корректно работает, если сортировать нечего.
2. **Массив только из чётных элементов**
   - *Вход:* `4 | 10 4 6 2`
   - *Выход:* `2 4 6 10`
   - *Значимость:* Гарантирует, что алгоритм корректно отрабатывает максимальное количество раз.
3. **Массив с нулями и отрицательными числами**
   - *Вход:* `5 | -3 -2 0 4 -4`
   - *Выход:* `-3 -4 -2 0 4`
   - *Значимость:* Проверяет работу со знаками и гарантирует, что нечётные числа остаются на своих местах, а ноль корректно обрабатывается как чётное число.
