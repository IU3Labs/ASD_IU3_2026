# ЛР2. Базовые структуры данных

## 1A. Очередь с приоритетом

В массиве родитель расположен по индексу `(i - 1) / 2`, дети — по индексам `2*i + 1` и `2*i + 2`. После добавления элемент поднимается к корню, пока он меньше родителя. При извлечении последний элемент переносится на место минимума и опускается к меньшему ребёнку. Так минимум всегда доступен в корне.

`poll` занимает O(log n), `peek`, `size` и `isEmpty` — O(1). Для `add` просеивание занимает O(log n), удвоение массива стоит O(n) в отдельном вызове и O(1) амортизированно на вставку. Итого O(log n) амортизированно. Оценки предполагают O(1) для сравнения элементов. Память пропорциональна ёмкости массива, которая после удалений не уменьшается.

Пример: после добавления 4, −2, −2 извлечения дают −2, −2, 4; очередной poll бросает NoSuchElementException. Проверяются повторы и опустошение очереди.
