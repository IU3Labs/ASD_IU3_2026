# Отчет

## Задача 1C. Удаление по значению

Добавить операцию `boolean remove(T item)` — удаление первого вхождения элемента по значению за \(O(n)\). Восстановить свойство кучи после удаления.

### Идея решения

Так как куча — это массив, мы просто проходим по нему циклом (за \(O(n)\)) и ищем элемент с нужным значением. 
Если нашли на индексе `i`:
1. Ставим на место `i` последний элемент массива.
2. Уменьшаем размер.
3. Восстанавливаем кучу: вызываем `siftDown(i)` и `siftUp(i)`. Новый элемент на позиции `i` может быть больше детей (тогда сработает `siftDown`) или меньше родителя (тогда сработает `siftUp`). Вызов обоих методов гарантирует корректность.

### Асимптотика

- `remove`: `O(n)` на поиск + `O(log n)` на восстановление кучи = **`O(n)`**.
- Доп. память: `O(1)`.

### Проверки

- Удаление корня: дерево перестраивается, следующий минимум выходит первым.
- Удаление из середины кучи: свойство кучи сохраняется.
- Удаление несуществующего элемента: возвращается `false`, размер не меняется.
- Удаление из пустой очереди: возвращается `false`.
- Удаление при дубликатах: удаляется только первое вхождение.
