# Отчет

## Задача 2B. Хеш-таблица с квадратичным пробированием

Реализовать таблицу с шагом `c1*i + c2*i^2` (c1=1, c2=3). Сравнить среднее число проб с линейным вариантом.

### Идея решения

Вместо того чтобы искать свободную ячейку подряд (как в 2A), мы прыгаем по формуле `base + i + 3*i^2`.
Это помогает избежать "кластеризации" — когда подряд идут длинные цепочки занятых ячеек, из-за которых поиск становится очень медленным.
Код почти идентичен 2A, меняется только строчка вычисления `probeIndex`.

### Асимптотика

- В среднем **`O(1)`** на операции, как и в 2A.
- При правильной настройке ёмкости (степень двойки) гарантируется, что мы обойдем все ячейки и не зациклимся.

### Замеры

Для 50 000 случайных ключей:
- Линейное пробирование (2A): среднее число проб ≈ ... (вставь свои цифры)
- Квадратичное пробирование (2B): среднее число проб ≈ ... 

**Вывод:** Квадратичное пробирование дает меньше проб при высокой нагрузке, так как уменьшает кластеризацию.

### Проверки

- Вставка/поиск совпадающих ключей.
- Удаление и повторная вставка.
- Разрешение коллизий (ключи 1, 17, 33).
