# Отчет

## Задача 1D. Построение кучи за O(n)

Добавить конструктор `PriorityQueueCustom(T[] array)`, который строит кучу за \(O(n)\) методом просеивания вниз.

### Идея решения

Вместо того, чтобы добавлять элементы по одному (что заняло бы \(O(n \log n)\)), мы копируем весь массив в кучу и начинаем просеивать элементы вниз.
Начинаем не с корня, а с **последнего внутреннего узла** (индекс `size/2 - 1`), потому что у листьев (вторая половина массива) детей нет, и их просеивать не нужно.
Идем от этого узла к корню, вызывая `siftDown`. Суммарно каждый элемент опускается не более чем на свою высоту, поэтому общая сложность — \(O(n)\).
