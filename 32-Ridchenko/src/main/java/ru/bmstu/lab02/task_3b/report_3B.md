# Отчет

## Задача 3B. Частота слов

Подсчёт частоты слов в тексте с игнорированием регистра и знаков препинания.

### Идея решения
Текст приводится к нижнему регистру и очищается от знаков препинания.
Для подсчёта используется упрощённая ассоциативная структура (список ключей и значений).
Затем список сортируется по убыванию частоты, и берутся первые `n` элементов.

### Асимптотика
Подсчёт: `O(L)` по длине текста. Сортировка: `O(V \log V)` по количеству уникальных слов.

### Проверки
- "Hello hello world" → hello: 2, world: 1.
- Игнорирование пунктуации и регистра.
- Пустой текст.
