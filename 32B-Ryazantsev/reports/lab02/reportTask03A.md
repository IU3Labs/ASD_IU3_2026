## Задача 3A. K наибольших элементов

Реализация: [TopK.java](../../src/main/java/ru/bmstu/lab02/TopK.java).

### Идея решения

В куче хранится не более k элементов. После заполнения кучи её минимум становится порогом.
Если очередное число больше порога, оно вытесняет текущий минимум. В конце минимумы
извлекаются с записью в результирующий массив с конца, поэтому список выходит по убыванию.
Входной список обходится итератором, чтобы и для связного списка не возникло обращений по индексу.

### Асимптотика

Пусть m — меньшая величина из k и n. При m ≥ 2 время O(n log m), при m = 1 время O(n).
При m = 0 работа завершается сразу. Дополнительная память — O(m) под кучу и результат.
Равные элементы учитываются по отдельности. Результат доступен для чтения.

JUnit 5: прошли 13 тестов, без ошибок и пропусков.
Тестовый класс: [TopKTest.java](../../src/test/java/ru/bmstu/lab02/TopKTest.java).

| Юнит-тест | Что проверяет |
|---|---|
| `shouldReturnDescendingResultAndLeaveInputIntact` | Результат идёт по убыванию, вход не меняется. |
| `shouldKeepEqualElementsAtCutoff` | Равные элементы на границе отбора сохраняются. |
| `shouldReturnOnlyMaximumWhenKIsOne` | При k = 1 возвращается максимум. |
| `shouldReturnEmptyResultWhenKIsZero` | При k = 0 результат пуст. |
| `shouldReturnEmptyResultForEmptyInput` | При пустом входе результат пуст. |
| `shouldReturnAllElementsWhenKExceedsInputSize` | При k больше размера возвращаются все элементы. |
| `shouldRejectNegativeKAndNullInput` | Некорректное k и вход null отклоняются. |
| `shouldRejectNullElementDuringSelection` | Элемент null при отборе отклоняется. |
| `shouldMatchSortingOnSequentialAccessList` | Результат на списке с последовательным доступом сверяется с сортировкой. |
| `shouldProvideListReadOperations` | Проверяются операции чтения списка. |
| `shouldCopyArrayWithoutExposingStorage` | Выдача массива не раскрывает внутреннее хранилище. |
| `shouldIterateBothWaysAndRespectListBounds` | Проверяется двунаправленный обход и его границы. |
| `shouldRejectListMutations` | Изменения результата отклоняются. |
