## Задача 1A. Очередь с приоритетом

Реализация: [PriorityQueueCustom.java](../../src/main/java/ru/bmstu/lab02/PriorityQueueCustom.java).

### Идея решения

Куча лежит в массиве. У узла с индексом `i` дети находятся на местах `2*i + 1` и `2*i + 2`,
а родитель — на месте `(i - 1) / 2`. После вставки новый элемент поднимается, пока он меньше
родителя. При извлечении минимума на место корня ставится последний элемент и опускается через
меньшего ребёнка. Для двух операций есть отдельные методы `siftUp` и `siftDown`.

### Асимптотика

| Операция | Время |
|---|---|
| `add` | O(log n) амортизированно. Отдельная вставка при росте массива — O(n) |
| `poll` | O(log n) |
| `peek`, `size`, `isEmpty` | O(1) |

Массив удваивается и выделяет O(C) памяти, где C — текущая ёмкость. При росте до n элементов
это O(n). После извлечений ёмкость сохраняется для следующих вставок.

### Проверки

JUnit 5: прошли 12 тестов, без ошибок и пропусков.
Тестовый класс: [PriorityQueueCustomTest.java](../../src/test/java/ru/bmstu/lab02/PriorityQueueCustomTest.java).

| Юнит-тест | Что проверяет |
|---|---|
| `shouldStartEmpty` | В новой очереди нет элементов. |
| `shouldThrowWhenPollingEmptyQueue` | Извлечение из пустой очереди даёт исключение. |
| `shouldPeekNullWhenEmpty` | Просмотр пустой очереди возвращает null. |
| `shouldPeekWithoutRemoving` | Просмотр минимума сохраняет размер очереди. |
| `shouldReturnToEmptyAfterOnePoll` | После извлечения единственного значения очередь пуста. |
| `shouldReuseQueueAfterDrainingIt` | После опустошения очередь можно использовать снова. |
| `shouldKeepDuplicates` | Одинаковые элементы учитываются по отдельности. |
| `shouldOrderIntegerExtremes` | Крайние значения int извлекаются в верном порядке. |
| `shouldGrowAndDrainDescendingInputInOrder` | Убывающий вход вызывает расширение, при извлечении порядок возрастающий. |
| `shouldRejectNullWithoutChangingSize` | Вставка null отклоняется. |
| `shouldOrderStringsByNaturalOrder` | Строки извлекаются в естественном порядке. |
| `shouldMatchStandardQueueDuringMixedOperations` | Смешанные операции сверяются со стандартной очередью. |
