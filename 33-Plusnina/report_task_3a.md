# Лабораторная работа № 2. Структуры данных

## Задание 3А. Поиск k наибольших элементов

### 1. Цель работы

Реализовать алгоритм поиска `k` наибольших элементов массива с использованием собственной очереди с приоритетом на основе бинарной минимальной кучи. Обеспечить временную сложность `O(n log k)` при `k ≥ 1`.

### 2. Реализация

**Файл реализации:** `src/main/java/ru/bmstu/lab2/TopK.java`

**Файл модульных тестов:** `src/test/java/ru/bmstu/lab2/TopKTest.java`

Для решения используется класс `PriorityQueueCustom<Integer>`, разработанный в задании 1А. Стандартная библиотечная очередь с приоритетом не применяется.

Метод `topK(int[] numbers, int k)` обрабатывает входной массив и возвращает `k` наибольших элементов в порядке убывания.

### 3. Алгоритм работы

1. Проверяются входные аргументы и значение `k`.
2. Создаётся пустая минимальная куча.
3. Элементы массива последовательно просматриваются.
4. Пока размер кучи меньше `k`, текущий элемент добавляется в неё.
5. Когда куча содержит `k` элементов, текущий элемент сравнивается с минимальным элементом кучи.
6. Если текущий элемент больше минимального, минимум удаляется, а новый элемент добавляется.
7. После обработки массива в куче остаются `k` наибольших элементов.
8. Элементы извлекаются из кучи и записываются в результирующий массив с конца, чтобы получить порядок убывания.

### 4. Оценка сложности

Обозначим:

- `n` — количество элементов исходного массива;
- `k` — количество искомых наибольших элементов.

| Операция | Сложность |
|---|---|
| Просмотр исходного массива | `O(n)` |
| Добавление элемента в кучу | `O(log k)` |
| Извлечение минимального элемента | `O(log k)` |
| Просмотр минимального элемента | `O(1)` |
| Формирование результата | `O(k log k)` |

Общая временная сложность при `k ≥ 1`:

`O(n log(k + 1))`

Для `k ≥ 2` она обычно записывается как `O(n log k)`.

Дополнительная пространственная сложность:

`O(k)`

Поскольку размер кучи ограничен величиной `k`, алгоритм не требует сортировки всего исходного массива.

### 5. Примеры работы

**Пример 1.**

Входные данные:

`numbers = [4, 1, 9, 2, 7]`, `k = 3`

Результат:

`[9, 7, 4]`

**Пример 2. Повторяющиеся значения.**

Входные данные:

`numbers = [5, 5, 1, 3]`, `k = 2`

Результат:

`[5, 5]`

**Пример 3. Отрицательные числа.**

Входные данные:

`numbers = [-8, -2, -5, -1]`, `k = 2`

Результат:

`[-1, -2]`
