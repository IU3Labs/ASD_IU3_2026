# Отчёт по задаче 1A — Базовая очередь с приоритетом

**Лабораторная работа:** №2 — структуры данных  
**Группа:** ИУ3-32  
**ФИО:** Щукин Алексей Романович  
**Модуль:** `32-Shchukin`  
**Стоимость задачи:** 2 балла  
**Класс:** `ru.bmstu.lab2.task_1.PriorityQueueCustom`

## 1. Условие задачи

Реализовать очередь с приоритетом на динамическом массиве: `add`, `poll`, `peek`, `size`, `isEmpty`.
Элементы извлекаются в порядке неубывания; извлечение из пустой очереди вызывает `NoSuchElementException`.

## 2. Идея и реализация алгоритма

Элементы хранятся в двоичной минимальной куче. Для узла с индексом `i` дети находятся по индексам
`2*i + 1` и `2*i + 2`, родитель — `(i - 1) / 2`. При добавлении новый элемент поднимается методом
`siftUp`; при извлечении корень заменяется последним элементом, после чего вызывается `siftDown`.
При заполнении массива ёмкость увеличивается в два раза.

**Обоснование:** куча позволяет получать минимум без поиска по всему массиву, а операции просеивания
затрагивают не больше одной ветви дерева.

## 3. Анализ асимптотики

| Операция | Время | Дополнительная память |
|---|---|---|
| `add` | O(log n) амортизированно | O(1) обычно; O(n) при расширении |
| `poll` | O(log n) | O(1) |
| `peek`, `size`, `isEmpty` | O(1) | O(1) |

Высота кучи равна O(log n). Расширение массива может потребовать O(n) времени на отдельном добавлении,
но при удвоении ёмкости его амортизированная стоимость постоянна. Сама структура занимает O(n) памяти.

## 4. Граничные случаи и тестирование

| Проверка | Ожидаемый результат | Назначение |
|---|---|---|
| `[8, 2, 7, 1, 5]` | Извлечение `1, 2, 5, 7, 8` | Порядок элементов |
| Пустая очередь, `poll()` | `NoSuchElementException` | Обработка пустой структуры |
| `[2, 1, 2, 1]` | Извлечение `1, 1, 2, 2` | Повторяющиеся значения |
| Добавление 1000 чисел | Размер 1000, верный порядок | Автоматическое расширение |

Дополнительно проверены отрицательные числа, `peek`, повторное использование очереди и `null`.
Время работы на 10 000, 50 000 и 100 000 элементов сравнивается со стандартной библиотекой в `benchmarks.md`.
