# Отчёт по задаче 1C — Удаление элемента по значению

**Лабораторная работа:** №2 — структуры данных

**Стоимость задачи:** 2 балла  
**Класс:** `ru.bmstu.lab2.task_1.PriorityQueueCustom`

## 1. Условие задачи

Реализовать `boolean remove(T item)`, удаляющий первое найденное в куче вхождение значения
за O(n). После удаления должна сохраняться корректность кучи.

## 2. Идея и реализация алгоритма

Метод последовательно ищет значение по массиву кучи. Найденная позиция заменяется последним
элементом. Если заменивший элемент имеет более высокий приоритет, чем родитель, он поднимается
методом `siftUp`; иначе выполняется `siftDown`.

**Обоснование:** в куче нет быстрого поиска произвольного значения, поэтому требуется O(n)
на его нахождение. Просеивание позволяет восстановить свойство кучи без полной перестройки.

## 3. Анализ асимптотики

Поиск элемента требует O(n) в худшем случае, а восстановление кучи — O(log n).
Суммарная сложность — **O(n)** по времени и **O(1)** по дополнительной памяти.

## 4. Граничные случаи и тестирование

| Проверка | Ожидаемый результат | Назначение |
|---|---|---|
| Удаление корня | Новый минимум корректен | Просеивание вниз |
| Удаление `8` из `[1, 5, 2, 8, 6, 3, 4]` | Остальные числа извлекаются по порядку | Просеивание вверх |
| Удаление отсутствующего `9` | `false`, размер не меняется | Поиск без совпадения |
| Удаление из пустой очереди | `false` | Граничный случай |
| Удаление из `[2, 2, 2]` | Остаются два элемента `2` | Только одно вхождение |

Дополнительно проверены удаление последнего элемента и работа `remove` в max-heap.
