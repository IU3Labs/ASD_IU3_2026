## Условие

Используя собственную хеш-таблицу, реализовать `countWords(String text)`: подсчёт частоты слов без учёта
регистра, с отбрасыванием знаков препинания. Обработать текст объёмом около 1 МБ и вывести 10 самых частых
слов.

## Идея

**Что считается словом.** Максимальная последовательность букв и цифр любого алфавита
(`Character.isLetterOrDigit`). Всё остальное — пробелы, переводы строк, знаки препинания, дефисы,
апострофы — разделитель. Поэтому `well-known` даёт два слова `well` и `known`, а `don't` — `don` и `t`.
Это простое и однозначное правило; оно не требует регулярных выражений и одинаково работает для русского
и английского текста.

**Подсчёт** ([`countWords`, строки 43–58](WordFrequency.java#L43-L58)):

1. Текст один раз приводится к нижнему регистру (строка 45) — так `Cat`, `cat` и `CAT` становятся одним
   словом. Используется `Locale.ROOT`, чтобы результат не зависел от языка системы.
2. Один проход по символам с переменной `start` — началом текущего слова (`-1`, если мы вне слова).
   Буква после разделителя открывает слово (строки 50–51), разделитель после буквы закрывает его и
   увеличивает счётчик (строки 52–54).
3. Цикл идёт до `i == length` **включительно**: позиция за концом текста считается разделителем, и слово
   в самом конце текста тоже засчитывается без отдельной проверки после цикла
   (тест `shouldCountWordAtVeryEndOfText`).

Счётчики хранятся в [`HashMapCustom<String, Integer>`](../task_2a/HashMapCustom.java) из задачи 2A:
слово → число вхождений.

**Отклонение от сигнатуры из условия.** В условии указан тип результата `Map<String, Integer>`.
`java.util.Map` — это интерфейс стандартной библиотеки, и чтобы его реализовать, пришлось бы написать ещё
около 20 методов. Поэтому `countWords` возвращает саму `HashMapCustom<String, Integer>` — свою таблицу,
как требует задание.

**Топ слов** ([`topWords`, строки 68–76](WordFrequency.java#L68-L76)): все пары из таблицы копируются в
список и сортируются по убыванию частоты, а при равной частоте — по алфавиту, чтобы результат был
однозначным.

## Асимптотика

`L` — длина текста, `w` — число слов, `u` — число уникальных слов.

| Строки | Стоимость | Раз | Вклад |
|--------|-----------|-----|-------|
| [45](WordFrequency.java#L45) — `toLowerCase` | O(L) | 1 | O(L) |
| [48–56](WordFrequency.java#L48-L56) — проход по символам | O(1) | L + 1 | O(L) |
| [53](WordFrequency.java#L53) → [79–80](WordFrequency.java#L79-L80) — `substring` + `get` + `put` | O(длина слова) в среднем | w | O(L) |
| [73](WordFrequency.java#L73) — копирование пар в список | O(1) | u | O(m), m — ёмкость |
| [74](WordFrequency.java#L74) — сортировка | O(u log u) | 1 | O(u log u) |

Строка 53 стоит O(длина слова), а не O(1): `substring` копирует символы, а `hashCode` и `equals` строки
проходят по ним. Сумма длин всех слов не больше L, поэтому весь подсчёт — **O(L) в среднем**.
Топ слов — **O(u log u)**. Память — O(L) на копию текста в нижнем регистре и O(u) на таблицу.

## Тесты

| Тест | Что проверяет |
|------|---------------|
| `shouldCountWordsIgnoringCase` | `Cat`, `cat`, `CAT` — одно слово |
| `shouldDropPunctuation` | запятые, многоточия, скобки, `!` и `?` отбрасываются |
| `shouldHandleCyrillicAndDigits` | русские буквы (включая `Ё`) и числа |
| `shouldSplitOnHyphensApostrophesAndLineBreaks` | дефис, апостроф, табуляция и перевод строки — разделители |
| `shouldReturnEmptyCountsForTextWithoutWords` | пустой текст и текст из одной пунктуации |
| `shouldCountWordAtVeryEndOfText` | слово в самом конце текста без разделителя после него |
| `shouldReturnTopWordsByFrequencyThenAlphabetically` | порядок топа, в том числе при равных частотах |
| `shouldReturnAllWordsWhenLimitExceedsDistinctCount` | лимит больше числа слов и лимит 0 |
| `shouldRejectNegativeLimit` | отрицательный лимит отклоняется |
| `shouldMatchReferenceCountingOnRandomText` | 20 000 случайных слов с разной пунктуацией — сверка с подсчётом через `java.util.HashMap` |
