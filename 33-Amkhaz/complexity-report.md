# Анализ сложности алгоритмов — Lab 1

## Задача 32 — сумма произведений пар
Каждый элемент обрабатывается один раз, с постоянным числом операций.
- Время: **O(n)**
- Дополнительная память: **O(1)**

## Задача 33 — количество инверсий
Сортировка слиянием выполняет O(n) работы на каждом из O(log n) уровней.
- Время: **O(n log n)**
- Дополнительная память: **O(n)** для временного массива и рекурсии.

## Задача 34 — максимальная сумма подмассива
Алгоритм Кадане обрабатывает каждый элемент один раз.
- Время: **O(n)**
- Дополнительная память: **O(1)**

## Задача 49 — сумма каждой строки матрицы
Все n·m элементов считываются и обрабатываются один раз.
- Время: **O(nm)**
- Дополнительная память: **O(1)**

## Задача 50 — сумма каждого столбца матрицы
Все n·m элементов обрабатываются один раз; массив сумм содержит m значений.
- Время: **O(nm)**
- Дополнительная память: **O(m)**

## Задача 54 — сумма главной диагонали
Реализация считывает все n² элементов и проверяет индексы.
- Время: **O(n²)**
- Дополнительная память: **O(1)**

## Задача 55 — сумма побочной диагонали
Реализация считывает все n² элементов и проверяет условие i + j = n − 1.
- Время: **O(n²)**
- Дополнительная память: **O(1)**
