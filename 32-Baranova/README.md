## PriorityQueueCustom

Очередь с приоритетом реализована на основе минимальной
бинарной кучи, элементы хранятся в динамическом массиве.

| Операция | Асимптотика |
|---|---|
| add | O(log n) амортизированно |
| poll | O(log n) |
| peek | O(1) |
| remove | O(n) |
| size | O(1) |
| isEmpty | O(1) |
| Построение из массива | O(n) |

## HashMapCustom

Хеш-таблица реализована на основе массивов с линейным
пробированием. Для удалённых ячеек используется маркер
DELETED, при превышении коэффициента загрузки 0.75
вместимость увеличивается в два раза.

| Операция | Средняя асимптотика |
|---|---|
| put | O(1) амортизированно |
| get | O(1) |
| containsKey | O(1) |
| remove | O(1) |
| size | O(1) |
| capacity | O(1) |

При большом количестве коллизий время поиска возрастает.
