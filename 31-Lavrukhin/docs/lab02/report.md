## Очередь с приоритетом

Двоичная куча хранится в массиве. Родитель имеет приоритет не ниже любого из своих детей, поэтому вершина всегда содержит первый по приоритету элемент. По умолчанию порядок естественный. Передача обратного компаратора превращает ту же структуру в max-heap.

| Операция | Время | Обоснование |
|---|---|---|
| `peek`, `size`, `isEmpty` | O(1) | Одно обращение к полю или ячейке |
| `add` | O(log n) амортизированно | Элемент поднимается по одной ветви. Удвоение массива занимает O(n) для отдельной вставки |
| `poll` | O(log n) | Последний элемент замещает вершину и опускается до подходящего уровня |
| `remove` | O(n) | Линейный поиск по равенству, затем не более O(log n) на восстановление |
| Конструктор из массива | O(n) | У большинства узлов малая высота. Сумма высот ограничена сверху рядом n/2 + n/4 + … |

При удалении из середины последний элемент может оказаться меньше нового родителя. В этом случае он поднимается, в остальных случаях достаточно просеивания вниз. Конструктор из массива обрабатывает внутренние узлы от последнего к корню, когда обе дочерние кучи уже готовы. Очередь занимает O(C) памяти, где C — выделенная ёмкость, зависящая от максимального достигнутого размера. При извлечении освободившаяся ссылка обнуляется.

## Скользящий минимум

В очереди хранятся индексы, упорядоченные по значениям исходного массива. После добавления правой границы окна с вершины удаляются индексы левее окна. Оставшаяся вершина принадлежит окну и содержит его минимум. Равные значения в разных позициях обрабатываются независимо.

Каждый индекс добавляется один раз и удаляется не более одного раза. Для массива длины n время составляет O(n log n). На убывающем массиве устаревшие индексы могут оставаться внутри кучи, поэтому дополнительная память достигает O(n). Выход содержит n − k + 1 значений.

## Примеры проверок

| Действие | Ожидаемый результат | Что проверяется |
|---|---|---|
| Извлечь вершину пустой очереди | `NoSuchElementException` | Контракт пустой очереди |
| Из кучи [1, 8, 2, 9, 10, 3, 4] удалить 9 | Извлечение даёт 1, 2, 3, 4, 8, 10 | Заместивший элемент 4 поднимается выше 8 |
| Из кучи [2, 1, 2, 2] удалить 2 | Остаются 1, 2, 2 | Удаляется одно вхождение |
| Окно 2 в массиве [−4, 2, −1, −1, 3, 4] | [−4, −1, −1, −1, 3] | Уход прежнего минимума и повторы |

В Maven-проекте 13 тестов для очереди и 4 для скользящего минимума. На массиве из 200 000 элементов с окном 1 000 каждое из 199 001 значений сверяется с прямым перебором. Для воспроизведения тестов и проверки порога покрытия 80% выполните `mvn clean verify` из папки проекта.
