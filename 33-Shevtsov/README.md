# Лабораторная работа № 2 · ИУ3-33Б

Задачи 1A, 1D и 2A. [Отчёт и расчёт асимптотики](report.md) · [Замеры](benchmarks.md).

## Запуск в IntelliJ IDEA

1. Распакуйте архив и откройте корневой `pom.xml` как проект через **File → Open**.
2. Если SDK ещё не выбран, откройте **File → Project Structure → Project → SDK** и выберите JDK 25.
   Его можно скачать через **Download JDK**. JDK 25 нужен для сборки всего проекта с примером курса.
   Отдельный модуль лабораторной можно собирать и на JDK 21.
3. Дождитесь загрузки Maven-зависимостей. В окне **Maven** раскройте **33-Shevtsov → Lifecycle**
   и запустите **test**. Эквивалентная команда из корня проекта при установленном Maven —
   `mvn -pl 33-Shevtsov clean test`.
4. HTML-отчёт о покрытии появится в `33-Shevtsov/target/site/jacoco/index.html`.
   Для повторного замера откройте класс `Lab02Benchmark` под `src/test/java` и нажмите ▶ рядом с `main`.
   В параметрах запуска можно задать `-Xms512m -Xmx512m`, как в приведённых замерах.

## Подготовка к сдаче

1. Откройте локальный клон своего форка курса. Создайте ветку ЛР2 на основе актуальной основной ветки курса,
   если в ней ещё нет вашего решения ЛР2. Пример команды из основной ветки —
   `git switch -c lab02-Shevtsov-33B`.
2. Перенесите папку `33-Shevtsov` в корень клона и переименуйте её в `33-Shevtsov`, подставив свою фамилию
   латиницей. Измените `artifactId` в POM этого модуля и добавьте `<module>33-Shevtsov</module>` в
   `<modules>` корневого POM клона. Если личный модуль уже есть, добавьте исходники, тесты и материалы ЛР2
   в него, сверив настройки его POM. Заполните поле ФИО в отчёте.
3. Запустите тесты, указав в Maven-команде фактическое имя модуля. Проверьте `git status` и `git diff`.
   Сделайте коммиты по смыслу, например `feat: implement lab02 data structures` и
   `docs: describe lab02 algorithms and benchmark results`.
4. Отправьте ветку в свой форк — `git push -u origin lab02-Shevtsov-33B`. Откройте **Compare & pull request**,
   выберите основную ветку репозитория курса как **base**, свою ветку как **compare** и проверьте
   **Files changed**. По условию в PR должны попасть только изменения ЛР2.
5. Укажите в описании PR ФИО, группу ИУ3-33Б и ЛР № 2. Добавьте задачи 1A, 1D, 2A, таблицы операций
   с асимптотикой и ключевые решения из `report.md`, таблицы замеров и вывод из `benchmarks.md`.
