# Лабораторная работа №2

Габитов Артём Эльдарович, ИУ3-31Б.

Задачи 1A, 1B, 1C, 1D — 8 баллов.

Очередь `PriorityQueueCustom<T>` реализована на двоичной куче в расширяемом массиве.
Массив выбран потому, что родителя и детей удобно находить по индексам:
родитель — `(i - 1) / 2`, дети — `2*i + 1` и `2*i + 2`.

## 1A. Базовая очередь

Добавленный элемент поднимается методом `siftUp`.
При извлечении корень заменяется последним элементом и опускается через `siftDown`.
Заполненный массив расширяется вдвое. Пустые `poll` и `peek` выбрасывают `NoSuchElementException`.

Пример: добавить 8, 3, 5, 1 → извлечь 1, 3, 5, 8. Проверяется порядок выдачи.

## 1B. Компаратор

Без компаратора используется естественный порядок, с `Comparator.reverseOrder()` — обратный.
Код просеивания одинаковый, меняется только правило сравнения.

Пример: для 2, 9, 1, 5 min-heap выдаёт 1, 2, 5, 9, max-heap — 9, 5, 2, 1.
Проверяются оба режима.

## 1C. Удаление по значению

`remove` находит первое совпадение через `equals` в массиве кучи.
На его место ставится последний элемент, затем выполняется подъём или спуск.
Если совпадения нет, возвращается `false`.

Пример: из 1, 2, 2, 3 удалить 2 → остаётся 1, 2, 3. Проверяется удаление одного повтора.
Отдельно проверены удаление корня, середины, отсутствующего элемента и пустая очередь.

## 1D. Построение из массива

Данные копируются, затем `siftDown` вызывается от последнего внутреннего узла к корню.
Большинство узлов находится близко к листьям, поэтому суммарная работа — O(n).

Пример: из массива 8, 3, 5, 1 построить очередь → извлечь 1, 3, 5, 8.
Проверяется порядок и отсутствие изменения исходного массива.

## Время и память

n — количество элементов, C — выделенная ёмкость массива.

| Операция | Время | Обоснование |
|---|---|---|
| add | O(log n) амортизированно | Подъём по высоте кучи; расширения редкие |
| poll | O(log n) | Спуск по высоте кучи |
| peek, size, isEmpty | O(1) | Чтение корня или поля |
| remove | O(n) | Линейный поиск и восстановление за O(log n) |
| Построение из массива | O(n) | Копирование и просеивание снизу вверх |

Отдельная вставка с расширением массива требует O(n), поэтому оценка `add` амортизированная.
Очередь занимает O(C) памяти; при росте C = O(n), после удалений ёмкость не уменьшается.
Просеивание использует O(1) дополнительных переменных. Конструктор из массива выделяет O(n) памяти.
