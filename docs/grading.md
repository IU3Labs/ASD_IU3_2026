# Критерии оценки лабораторных работ (АСД)

Каждая лабораторная работа должна быть сдана для получения зачета. Критерий сдачи ЛР = замердженное решение.

---

## 1. Корректность решения

- Решение покрыто тестами (покрытие не менее 80 процентов)
- Отсутствие ошибок времени выполнения (Runtime Errors), зацикливаний, утечек памяти
- Асимптотика соответствует заявленной в условии (например, `O(n log n)` вместо `O(n^2)`)
- Присутствие файла расчета асимптотики.
- Асимптотика вычислена верно.

---

## 2. Качество кода и стиль

- Соблюдение правил из `style-guide.md` (именование, форматирование, длина методов, дублирование)
- Наличие комментариев (ключевые шаги, обоснование выбора структуры данных, сложные граничные случаи)

> Комментарии не должны быть избыточными или повторять код.

---

## 3. Тесты студента

- Тесты читаемы, названы понятно, не дублируют друг друга.

---

## 4. Оформление PR и коммитов

- В описании PR указаны ФИО, группа, номер лабораторной
- Коммиты атомарны и осмысленно названы (см. `style-guide.md`)
- Код разбит на логические части, нет «мегакоммитов» с сотнями строк изменений

---

## Дополнительные правила

- **Плагиат / совпадение кода** между студентами — работа не засчитывается, требуется решение дополнительных задач
- **Поздняя сдача:** для каждой задачи есть контрольный срок, сдача вне его возможна только при выделении дополнительных дат преподавателем или во время сессии
- **Доработка после ревью:** если работа отправлена на доработку, студент должен внести правки в ту же ветку и обновить PR. ПР не удаляется, а только изменяется.

---

## Что не допускается

- Использование сторонних библиотек для реализации структур данных (если в условии не разрешено).
- «Хардкод» ответов.

---

## Формат отчёта

Для лабораторных дополнительно требуется краткий текстовый отчёт (отдельным файлом, например, `report.md`):

- Описание идеи решения и обоснование выбора структуры данных.
- Анализ асимптотики (время и память).
- Примеры ручных тестов и объяснение, почему они важны.

---

## Апелляции

Если вы не согласны с оценкой, напишите преподавателю в течение **3 рабочих дней** после получения обратной связи. Укажите конкретные пункты критериев, с которыми несогласны, и приведите аргументы.
