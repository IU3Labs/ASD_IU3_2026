# Лабораторная работа №1

Александр Симонов, группа IU3-33B.

Решены задачи 49, 50, 56 и 57 из блока «Двумерные массивы и матрицы».
Каждая задача оценивается в 3 балла, всего 12 баллов.

## Сборка и тесты

Требуются JDK 25 и Maven. Из корня репозитория:

```bash
mvn -pl IU3-33B-Simonov -am clean verify
```

Команда запускает тесты и проверяет покрытие строк кода не ниже 80%.
Отчёт JaCoCo: `IU3-33B-Simonov/target/site/jacoco/index.html`.

## Запуск

После сборки из корня репозитория:

```bash
java -cp IU3-33B-Simonov/target/classes ru.bmstu.lab1.task_49.Main
java -cp IU3-33B-Simonov/target/classes ru.bmstu.lab1.task_50.Main
java -cp IU3-33B-Simonov/target/classes ru.bmstu.lab1.task_56.Main
java -cp IU3-33B-Simonov/target/classes ru.bmstu.lab1.task_57.Main
```

Каждая команда запускает отдельную задачу. Числа во входных данных разделяются пробелами или переводами строк.

| Задача | Ввод | Вывод |
|---|---|---|
| 49 | `n m`, затем `n * m` элементов матрицы по строкам | `n` сумм строк |
| 50 | `n m`, затем `n * m` элементов матрицы по строкам | `m` сумм столбцов |
| 56 | `n m k`, затем матрица A размера `n × m` и B размера `m × k` | Матрица произведения размера `n × k` |
| 57 | `n m`, затем `n * m` элементов матрицы по строкам | Элементы по спирали, начиная с левого верхнего угла по часовой стрелке |

Размеры матриц положительные. Элементы — целые числа типа `int`.
Суммы и произведения вычисляются в `long`; итоговые значения должны помещаться в этот тип.
Для спирального обхода число элементов должно помещаться в размер массива Java.

Идеи решений, расчёт асимптотики и примеры приведены в [report.md](report.md).
