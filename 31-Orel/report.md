## Расчёт асимптотики

Обозначения: `n` — длина массива (или число строк), `m` — число столбцов, `k` — число столбцов матрицы B.
Чтение входа само по себе занимает O(n) или O(n·m) и в оценки ниже не включается.

### Задача 16. Сортировка по модулю

**Идея.** Сортировка с составным компаратором: сначала по `|x|`, при равенстве — по самому `x`
(из `-x` и `x` меньше `-x`, значит отрицательный идёт первым). Модуль считается в `long`, потому что
`Math.abs(Integer.MIN_VALUE)` в `int` переполняется.

**Время.** Упаковка в `Integer[]` — O(n), сортировка TimSort — O(n log n), обратная распаковка — O(n).
Итого **O(n log n)**.
**Память.** Массив `Integer[]` и результат — **O(n)**.

### Задача 22. Сортировка по частоте

**Идея.** Сначала подсчитываем частоту каждого значения в `HashMap`, затем сортируем по
(частота по убыванию, значение по возрастанию). `HashMap` выбран, потому что значения — произвольные `int`
(до ±2·10^9), и массив-счётчик такого размера невозможен.

**Время.** Подсчёт: n операций `merge` по O(1) в среднем — O(n). Сортировка: O(n log n) сравнений,
каждое сравнение — два `get` за O(1). Итого **O(n log n)**.
**Память.** Словарь — до n записей, упакованный массив — n: **O(n)**.

### Задача 33. Количество инверсий

**Идея.** Сортировка слиянием. При слиянии отсортированных половин `L` и `R`, если текущий элемент `R[j]`
строго меньше `L[i]`, то он меньше и всех оставшихся элементов `L` (они не меньше `L[i]`), значит
он образует `middle - i` инверсий. Равные элементы инверсией не считаются, поэтому сравнение `<=`.
Ответ хранится в `long`: максимум n(n−1)/2 ≈ 5·10^9 при n = 10^5, что больше `Integer.MAX_VALUE`.

**Время.** Рекуррентное соотношение T(n) = 2T(n/2) + O(n) (слияние линейно).
По основной теореме (a = 2, b = 2, f(n) = n = n^(log_b a)) получаем **T(n) = O(n log n)**.
Наглядно: глубина рекурсии log₂ n уровней, на каждом уровне суммарно сливается n элементов.
**Память.** Рабочая копия и буфер слияния — по n элементов, стек рекурсии — O(log n). Итого **O(n)**.

### Задача 34. Максимальная сумма подмассива (Кадане)

**Идея.** `bestEndingHere` — максимальная сумма подмассива, оканчивающегося в позиции i:
`bestEndingHere(i) = max(a[i], bestEndingHere(i−1) + a[i])` — либо продолжаем предыдущий подмассив,
либо начинаем новый. Ответ — максимум этих значений. Инициализация первым элементом (а не нулём)
даёт правильный ответ для массива из одних отрицательных чисел (подмассив должен быть непустым).
Суммы в `long`: 10^5 · 2^31 не помещается в `int`.

**Время.** Один проход, на каждый элемент O(1) операций: **O(n)**.
**Память.** Две переменные: **O(1)**.

### Задача 53. Седловые точки

**Идея.** Предпосчитать минимум каждой строки `rowMin[i]` и максимум каждого столбца `colMax[j]`.
Элемент `a[i][j]` — седловая точка, если `a[i][j] == rowMin[i]` и `a[i][j] == colMax[j]`.
Наивная проверка каждого элемента по всей строке и столбцу стоила бы O(n·m·(n+m)).

**Время.** `rowMin` — O(n·m), `colMax` — O(n·m), финальная проверка — O(n·m). Итого **O(n·m)**.
**Память.** Массивы `rowMin` и `colMax` — **O(n + m)** (плюс список ответа, не больше n·m точек).

### Задача 56. Умножение матриц

**Идея.** Классическая формула `C[i][j] = Σ_t A[i][t] · B[t][j]`. Циклы упорядочены как i → t → j:
во внутреннем цикле строки `B[t]` и `C[i]` читаются подряд, это быстрее за счёт кэша, чем обход B по
столбцам. Элементы результата — `long`, чтобы произведения `int` не переполнялись.

**Время.** Три вложенных цикла: n · m · k итераций по O(1): **O(n·m·k)** — как в требовании.
**Память.** Только результирующая матрица n x k: **O(n·k)** — как в требовании.

### Задача 57. Спиральный обход

**Идея.** Храним четыре границы ещё не пройденной части: `top`, `bottom`, `left`, `right`.
За один виток проходим верхнюю строку слева направо, правый столбец сверху вниз, нижнюю строку справа налево,
левый столбец снизу вверх и сужаем границы. Если осталась одна строка или один столбец, обратные проходы
пропускаются, иначе элементы повторились бы.

**Время.** Каждый элемент записывается ровно один раз: **O(n·m)**.
**Память.** Результат из n·m элементов, сверх него — O(1).

### Задача 60. Острова из единиц

**Идея.** Обходим все клетки; встретив непосещённую единицу, запускаем BFS, который помечает весь остров,
и увеличиваем счётчик. Выбран BFS на массиве-очереди, а не рекурсивный DFS: на матрице 1000 x 1000
из единиц глубина рекурсии DFS достигла бы 10^6 и вызвала бы `StackOverflowError`.
Клетка `(r, c)` хранится в очереди одним числом `r · m + c`. Исходная матрица не меняется
(посещённость — в отдельном `boolean[][]`).

**Время.** Каждая клетка попадает в очередь не более одного раза (помечается при добавлении),
у каждой — 4 соседа. Внешний обход — n·m. Итого **O(n·m)**.
**Память.** `visited` — n·m, очередь — n·m: **O(n·m)**.
