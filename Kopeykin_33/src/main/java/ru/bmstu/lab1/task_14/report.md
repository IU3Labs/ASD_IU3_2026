# Отчёт по задаче №14: Сортировка вставками (по невозрастанию)

## 1. Идея решения
Левая часть массива $[0 \dots i-1]$ поддерживается отсортированной по невозрастанию. Текущий элемент `key = array[i]` сдвигает вправо все меньшие его элементы слева и встаёт на освободившееся место.

## 2. Анализ асимптотики
* **Время (Time Complexity):**
    * Лучший случай (массив уже отсортирован по убыванию): внутренний цикл `while` не выполняется, $T(n) = \Theta(n)$.
    * Худший и средний случаи (массив отсортирован по возрастанию): $\sum_{i=1}^{n-1} i = \frac{n(n - 1)}{2} = \Theta(n^2)$.
* **Память (Space Complexity):** $O(1)$ дополнительной памяти.

## 3. Примеры ручных тестов
* `5 | 12 11 13 5 6` $\rightarrow$ `13 12 11 6 5` (общий случай).
* `3 | 9 5 1` $\rightarrow$ `9 5 1` (лучший случай за линейное время).
