# Отчёт по задаче №37: Разворот массива

## 1. Идея решения
Используется техника двух указателей (`left = 0`, `right = n - 1`). На каждом шаге элементы `array[left]` и `array[right]` меняются местами прямо в исходном массиве (in-place), после чего указатели сдвигаются к центру.

## 2. Анализ асимптотики
* **Время (Time Complexity):** $\Theta(n)$ — выполняется ровно $\lfloor n / 2 \rfloor$ итераций обмена.
* **Память (Space Complexity):** $O(1)$ дополнительной памяти в соответствии с требованием модификации на месте.

## 3. Примеры ручных тестов
* `5 | 1 2 3 4 5` $\rightarrow$ `5 4 3 2 1` (нечётная длина — центральный элемент остаётся на месте).
* `4 | 10 20 30 40` $\rightarrow$ `40 30 20 10` (чётная длина).
