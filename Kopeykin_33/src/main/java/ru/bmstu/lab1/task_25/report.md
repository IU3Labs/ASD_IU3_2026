# Отчёт по задаче №25: Сумма элементов

## 1. Идея решения
Однопроходное суммирование элементов в 64-битный аккумулятор `long` для предотвращения переполнения 32-битного типа `int` при $n \le 10^5$.

## 2. Анализ асимптотики
* **Время (Time Complexity):** $\Theta(n)$ — ровно $n$ операций сложения за $O(1)$.
* **Память (Space Complexity):** $O(1)$ — потоковая обработка без выделения памяти под массив.

## 3. Примеры ручных тестов
* `5 | 10 -2 7 0 5` $\rightarrow$ `20` (смешанные знаки).
* `2 | 2000000000 2000000000` $\rightarrow$ `4000000000` (проверка отсутствия переполнения `Integer.MAX_VALUE`).
