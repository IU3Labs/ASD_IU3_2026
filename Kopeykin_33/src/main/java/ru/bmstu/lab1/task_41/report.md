# Отчёт по задаче №41: Удаление элемента

## 1. Идея решения
Применяется метод двух указателей (`i` — чтение, `writeIndex` — запись). Все элементы, не равные $x$, копируются в начало массива на позицию `writeIndex`.

## 2. Анализ асимптотики
* **Время (Time Complexity):** $\Theta(n)$ — один линейный проход по массиву.
* **Память (Space Complexity):** $O(1)$ дополнительной памяти.

## 3. Примеры ручных тестов
* `6 | 3 2 2 3 4 3 | 3` $\rightarrow$ `2 2 4` (удаление с краёв и из середины).
* `3 | 7 7 7 | 7` $\rightarrow$ пустая строка (граничный случай удаления всех элементов).
