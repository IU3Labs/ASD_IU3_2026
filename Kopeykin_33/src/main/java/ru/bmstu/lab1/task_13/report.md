# Отчёт по задаче №13: Сортировка выбором

## 1. Идея решения
Массив делится на отсортированный префикс и неотсортированный суффикс. На каждом шаге $i$ линейным поиском находится минимальный элемент в диапазоне $[i \dots n-1]$ и меняется местами с элементом на позиции $i$.

## 2. Анализ асимптотики
* **Время (Time Complexity):** Число сравнений не зависит от исходного порядка элементов и составляет $\sum_{i=0}^{n-2} (n - 1 - i) = \frac{n(n - 1)}{2} = \Theta(n^2)$. Количество обменов — $\Theta(n)$. Итоговая сложность: $O(n^2)$ во всех случаях.
* **Память (Space Complexity):** $O(1)$ вспомогательной памяти (сортировка на месте).

## 3. Примеры ручных тестов
* `5 | 64 25 12 22 11` $\rightarrow$ `11 12 22 25 64` (обратно упорядоченные и случайные данные).
* `4 | 0 -5 3 -5` $\rightarrow$ `-5 -5 0 3` (корректная обработка дубликатов и отрицательных чисел).
