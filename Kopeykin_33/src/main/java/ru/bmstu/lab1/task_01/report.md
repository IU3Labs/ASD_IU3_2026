# Отчёт по задаче №1: Максимум и минимум

## 1. Идея решения
Выполняется однопроходное чтение потока из $n$ чисел. Первое число инициализирует переменные `min` и `max`. Каждое последующее число за один шаг сравнивается с текущими экстремумами.

## 2. Анализ асимптотики
* **Время (Time Complexity):** $\Theta(n)$. Цикл выполняется ровно $n - 1$ раз, на каждой итерации совершается 2 сравнения за $O(1)$. Итоговая сложность — $O(n)$.
* **Память (Space Complexity):** $O(1)$. Элементы обрабатываются потоково без сохранения всего массива в памяти.

## 3. Примеры ручных тестов
* `6 | 3 1 9 -4 7 0` $\rightarrow$ `-4 9` (проверка положительных, отрицательных чисел и нуля).
* `4 | 5 5 5 5` $\rightarrow$ `5 5` (граничный случай: все элементы равны).
