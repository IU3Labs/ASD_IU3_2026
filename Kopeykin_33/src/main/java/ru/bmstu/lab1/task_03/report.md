# Отчёт по задаче №3: Подсчёт вхождений

## 1. Идея решения
Полный линейный перебор всех элементов массива со счётчиком совпадений с целевым значением $x$.

## 2. Анализ асимптотики
* **Время (Time Complexity):** $\Theta(n)$ во всех случаях, так как необходимо проверить каждый из $n$ элементов.
* **Память (Space Complexity):** $O(n)$ на хранение массива, $O(1)$ вспомогательной памяти.

## 3. Примеры ручных тестов
* `6 | 4 2 4 1 4 9 | 4` $\rightarrow$ `3` (несколько вхождений).
* `3 | 1 2 3 | 10` $\rightarrow$ `0` (отсутствие целевого элемента).
